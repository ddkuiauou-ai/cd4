# CD UX 콘셉트 비교 · 2026-10-09

## 검토 목적
숫자를 확인하러 왔다가 재미있어서 다른 종목도 구경하는 경험을 시각화한다. 제품 코드나 기존 DESIGN.md를 확정·변경하는 작업은 아니다.

## 비교안
- A 대회 관전판: 선명한 컬러 순위와 관전의 활기.
- B 대회 기록실: 개성 있는 기록표와 연속 탐색의 호기심. 무채색 금융 대시보드로 회귀하지 않는다.

## 사용자 선택 · 2026-10-09
사용자는 보정된 B ‘대회 기록실’ 이미지를 첨부하며 ‘금융스러우면서 CD의 성격을 잘 살린’ 버전이라고 평가했다. 후속 시안은 B를 시각 기준으로 삼는다.

선택된 이미지에서 유지할 핵심은 흰 읽기 표면과 정돈된 숫자, 개성 있는 명조 제목, 선명한 컬러 순위, 금색 선택·탐색 표시, 기록을 구분하는 괘선이다. 재미가 조회·탐색 과정에서 드러나는지 계속 판단한다. 선택 확인은 이미지의 모든 세부 요소나 전체 제품 구현의 승인을 뜻하지 않는다.

후속 진행 순서에 대한 사용자 정정: 작은 프로토타입으로 먼저 옮기기보다 현재 각 화면을 어떻게 바꿀지 이미지로 구체적으로 확인한다. 메인·랭킹·기업/종목 상세·지표별 상세·검색/최근 본의 모바일/데스크톱 시안을 검토한 뒤 동작 검증 또는 구현으로 진행한다. 범위와 순서는 [화면별 이미지 시안 계획](screen-plan.md)에 정리했다. 아래 ‘후속 프로토타입’ 보완점도 이 이미지 검토 단계부터 반영한다.

## 동일 조건
모바일 라이트 화면, 종목 시가총액 범위, 순위 발견 → SK하이닉스 확인 → 가까운 순위 탐색의 세 화면. 두 안 모두 같은 예시 데이터와 같은 기능을 사용한다. 보드의 숫자는 실제 시장 자료가 아닌 예시다.

## 예시 데이터
1 삼성전자 495조 유지 / 2 SK하이닉스 237조 ↑1 / 3 LG에너지솔루션 88조 ↓1 / 4 삼성바이오로직스 77조 ↑1 / 5 현대차 55조 ↓1.
SK하이닉스: 주가 326,000원 +1.20%, 이전 3위 → 현재 2위. 삼성전자와의 시총 차이 258조, LG에너지솔루션과의 차이 149조.

## 판단 기준
필요한 숫자를 바로 찾는가 / CD다운 인상이 남는가 / 옆 종목을 눌러보고 싶은가 / 긴 목록도 편하게 읽히는가.

## 표현의 경계
이름·별·빨강·금색의 친숙함을 바탕으로 한다. 실제 대회 참가, 매매, 실시간 데이터 기능을 암시하지 않는다. 순위와 주가 등락을 구별한다. 미리보기의 모바일 탭 상태를 이미지로 보여주며 실제 호버·키보드·애니메이션 동작은 후속 프로토타입에서 검증한다.

## 생성 방식
내장 imagegen 도구. a.prompt.txt와 b.prompt.txt에 도구에 전달한 정확한 프롬프트를 보존한다.

## 최종 비교 이미지
- [A · 대회 관전판](a-arena.png)
- [B · 대회 기록실](b-records.png)
- 생성 프롬프트: [A](a.prompt.txt), [B](b.prompt.txt)
- 한 차례 보정 프롬프트: [A](a.edit.prompt.txt), [B](b.edit.prompt.txt)
- 각 PNG의 JSON에는 초기 프롬프트와 보정 프롬프트, 입력 이미지 경로를 함께 보존한다.

## 검토 범위
두 보드는 표현과 흐름을 비교하는 정적 콘셉트 이미지다. 실제 터치·호버·키보드·반응형·접근성 검증이나 구현 승인 자료로 간주하지 않는다. 현재 제품 코드와 DESIGN.md는 변경하지 않았다.

독립 시각 검토에서 추가된 종목 홍보 문구와 왕관의 제거, 예시 데이터와 기준일 표시, A/B 표현의 차이를 확인했다. 방향 선택용 이미지로 검토했으며 사용성 검증을 통과한 화면으로 판정하지 않았다.

후속 프로토타입에 반영할 제한:
- A 상세 화면에서 가까운 순위로 이어지는 버튼이 이미지에 누락됐다. 연결 동선을 명시한다.
- B 순위 이동 화살표의 색이 일부 일관되지 않다. 순위 이동은 같은 중립 잉크, 주가 등락은 별도 의미 색으로 정리한다.
- B 미리보기를 여는 종목의 선택 상태와 주석의 연결 표시를 더 명확하게 한다.

이미지는 한 차례 일괄 보정 후 비교 자료로 보존한다. 실제 수치 표기와 전체 지표 메뉴, 다운로드 등 운영 기능의 세부 배치는 선택한 방향의 프로토타입에서 함께 검토한다.
