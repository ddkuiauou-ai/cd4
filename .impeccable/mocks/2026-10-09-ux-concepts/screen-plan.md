# B 대회 기록실 · 현행 화면별 이미지 시안 계획

2026-10-09

## 사용자가 정한 진행 순서
B의 전체적인 인상을 선택한 다음 단계는 현재 각 화면을 어떻게 바꿀지 이미지로 확인하는 것이다. 작은 프로토타입으로 먼저 옮기지 않는다. 화면별 이미지 검토 뒤 연결 흐름과 공통 규칙을 정리하고, 그 다음에 동작 검증 또는 제품 구현으로 진행한다.

## 목적
숫자를 확인하러 왔다가 재미있어서 다른 종목도 구경하는 서비스. B의 흰 읽기 표면, 명조 제목, 컬러 순위, 금색 선택, 기록표의 괘선을 각 화면의 역할에 맞게 확장한다. 기존 컴포넌트의 배치를 그대로 보존하는 것을 목표로 하지 않는다.

## 산출물 규칙
- 각 화면의 모바일·데스크톱 구성을 별도로 설계해 이미지로 확인한다. 데스크톱은 모바일을 넓혀 놓은 형태로 만들지 않는다.
- 긴 상세는 첫 화면과 하단 연속 화면을 나누어, 차트·비교·통계·연도별 데이터·CSV·다음 탐색의 실제 위치까지 확인한다.
- 동일한 데이터와 대상을 화면 사이에 유지하고 모든 숫자는 예시임을 표시한다.
- 지표별 랭킹의 공통 골격은 한 번 검토하되 범위·단위·문구가 다른 변형을 함께 보여준다. 상세 차트·조작이 다른 지표는 각각 독립된 시안으로 검토한다.
- 화면별로 ‘사용자의 질문 / 첫 화면의 답 / 하단 정보 순서 / 다음 행동 / 유지할 기능’을 짧게 붙인다.
- 날짜·기준·모집단과 기업/종목 구분을 읽을 수 있게 둔다. 아직 없는 매매·실시간·대회 참가·추천 기능은 넣지 않는다.
- 생성 이미지의 문구 오류·누락·색 의미는 검토사항으로 기록한다. 이미지를 기능 검증이나 구현 완료로 간주하지 않는다.

## 현행 화면 지도

### 1. 메인
- 경로: /dashboard
- 질문: 어떤 기록부터 구경할까?
- 제안 순서: TOP5와 전체 순위 진입 → 지표별 순위 색인 → 주가 흐름의 상승/하락/거래량 → 최근 본과 다운로드.
- 데스크톱은 TOP5와 흐름을 비교할 수 있는 별도 구역, 최근 본은 작은 색인 영역으로 둔다. 모바일은 첫 화면부터 목록을 읽게 한다.
- 주가 흐름의 대상은 시가총액 상위 20개 기업의 대표 보통주 안이다. 전시장 전체 상승률·거래량 순위로 표현하지 않는다.

### 2. 전체 랭킹 · 8종
| 화면 | 경로 | 독립적으로 확인할 차이 |
| --- | --- | --- |
| 기업 합산 시총 | /, /marketcaps | 합산 범위, 기업 상세 연결, 대표 보통주 가격의 별도 의미 |
| 종목별 시총 | /marketcap | 보통주·우선주 각각의 시총, 종목 상세 연결 |
| PER | /per | 배 단위, 저장된 공식 순위, 지표 설명 |
| PBR | /pbr | 배 단위, PER와 다른 정의 |
| EPS | /eps | 주당순이익, 원 단위 |
| BPS | /bps | 주당순자산, 원 단위 |
| 배당수익률 | /div | 지표값 %와 주가 등락 %의 위계 구분 |
| 주당배당금 | /dps | 원 단위의 주당배당금 |

공통 확인 내용: 7개 지표 탐색, 시총에서만 기업/종목 범위 선택, 현재 순위·이동량 묶음, 정확한 값과 관측일 펼침, 전체 CSV, 전체 개수·현재 범위·페이지 이동, 최근 본. 작은 차트는 ‘주가 추이’로 명시한다. 페이지 번호 변형은 별도 시각 세계를 만들지 않는다.

### 3. 기업 상세 · 2종
| 화면 | 경로 | 제안 정보 순서 |
| --- | --- | --- |
| 기업 기본 | /company/{id} | 기업 이름·범위 → 업종/설립일/홈페이지 → 연결 종목 → 기업 합산 시총 진입 |
| 기업 합산 시총 | /company/{id}/marketcap | 합산값·순위·기준일 → 구성 종목·비중 → 등록 종목 합계의 과거 기록 → 기간 통계·연도별 데이터 → CSV·인접 기업 |

기업 내부 탐색은 기업 정보/기업 합산 시총으로 유지하고, ‘이 기업의 종목’에서 보통주·우선주로 이동한다. PER 등 종목 지표로 이동할 때는 대상 종목을 명시한다. 공개된 기업 현재 합산값과 과거 등록 종목 부분 합계를 같은 시계열처럼 묶지 않는다.

### 4. 종목 기본·시총 상세 · 2종
| 화면 | 경로 | 제안 정보 순서 |
| --- | --- | --- |
| 종목 기본 | /security/{id} | 종목명·종류·티커·거래소 → 주가/등락/거래량 → 발행주식수 → 기업 정보·연결 종목·지표 진입 |
| 종목 시총 | /security/{id}/marketcap | 종목 시총·순위·기준일 → 해당 종목 추이 → 주가 이력 → 기업 내 위치 → 통계·연도별 기록·CSV → 인접 종목 |

기업 합산과 선택 종목의 값을 분리한다. 대상 이름·범위·현재 지표를 이동 후에도 인지할 수 있게 둔다.

### 5. 종목 재무지표 상세 · 6종
| 화면 | 경로 | 이미지에서 확인할 핵심 차트·조작 |
| --- | --- | --- |
| PER | /security/{id}/per | 추이, 기간 통계, 월별 히트맵·관측값 분포, 연도별 기록 |
| PBR | /security/{id}/pbr | 월간/연간 관측 평균 추이, 기간 통계, 연도별 기록 |
| EPS | /security/{id}/eps | 제공값 추이, 기간 통계, 연도별 마지막 관측값 |
| BPS | /security/{id}/bps | 연말 관측 막대, 최근연말/5·10·20년, 히트맵·분포 |
| 배당수익률 | /security/{id}/div | % 값, 제공 관측의 월간/연간 평균 추이, 연도별 기록 |
| 주당배당금 | /security/{id}/dps | 금액 막대+직전 기록 대비 변화율, 기간 선택, 히트맵·분포 |

각 화면에 지표 선택, 기준일·단위, 주가 이력, 동일 기업의 다른 종목, CSV, 계산식·자료 정보를 배치한다. 같은 카드·같은 차트의 제목만 바꾸는 시안으로 처리하지 않는다.

### 6. 검색·최근 본·메뉴
- 검색 열린 화면: 기업과 종목을 별도 행으로 구분한다. 기업 결과는 기업 기본 정보, 종목 결과는 해당 종목 시총으로 연결한다. 이름·코드·거래소·종류를 읽게 한다.
- 최근 본: 마지막 방문 지표·값·목적지, 개별 삭제·전체 삭제를 보존한다. 즐겨찾기나 실시간 관심종목으로 바꾸지 않는다.
- 메뉴: 메인/랭킹/검색, 최근 본, 테마, 7개 지표의 위치를 모바일·데스크톱 이미지에서 확인한다.
- 테마: 라이트/다크/기기 설정 선택을 표현한다. 전체 라이트 구성을 확정한 뒤 다크 변형을 검토한다.

### 7. 주요 상태
검색 결과 없음/검색 오류/최근 본 없음/상세 로딩/순위 미공개/공개됐지만 대상 0개/현재 지표값 없음/오류·404/조회 중 자료 갱신을 상태 시트로 검토한다. 데이터 부재와 0을 구별한다.

## 일관된 예시 데이터
선택된 B 보드의 종목 시총을 유지한다: 삼성전자 보통주495조, SK하이닉스237조, LG에너지솔루션88조, 삼성바이오로직스77조, 현대차55조. 기업 합산 시총 변형에서는 삼성전자우54조를 추가해 삼성전자 기업 합산549조로 구분한다. 모든 값은 실제 시장 자료가 아닌 예시다.

## 검토 순서
1. 메인·랭킹의 모바일/데스크톱 이미지로 공통 탐색과 읽기 규칙을 확인한다.
2. 기업·종목의 기본·시총 상세 이미지로 대상 구분과 정보 순서를 확인한다.
3. 지표별 상세 이미지로 각 차트와 하단 내용의 필요성을 검토한다.
4. 검색·최근 본·메뉴·주요 상태 이미지로 연결과 예외를 확인한다.
5. 전 화면을 나란히 대조해 표현과 흐름을 확정한 뒤 동작 검증 또는 구현으로 진행한다.

이 문서는 이미지 제작 범위와 순서를 정리한 계획이다. 화면별 이미지 제작 완료를 의미하지 않는다.
