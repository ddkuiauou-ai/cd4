# 공통 이미지 레이아웃 계약 · 2026-10-14

사용자 확정: 06 기업 합산 시총에서 구성 종목 버튼은 08 해당 종목 시총으로 연결. 모바일은 기업 전체와 모든 실제 구성 종목을 항상 노출. 제품 코드 대신 이미지로 검토.

## 공통 시각 규칙
- B 대회 기록실 유지. 흰 읽기 표면, 짙은 남색/검정 데이터, 진지하고 절제된 궁서풍 제목/로고, 빨강+금색 전체 브랜드와 별 원형 심볼, 색 있는 상위3순위, 얇은 빨강 섹션선.
- 실제 폰트 적용 아님. 이미지에 그린 궁서풍 방향.
- 모든 보드는 1536x1024 landscape 목표. 왼쪽 약1120px desktop, 오른쪽 약360px mobile, 얇은 간격. 화면들은 맨 위부터 같은 높이에서 시작. 보드 바깥의 큰 제목/데스크톱·모바일 라벨/기기 목업 없음.
- 전역 PC헤더: 전체 로고 / 메인 / 랭킹 / 기업·종목 검색 / 최근 본 / 테마. 항상 동일.
- 전역 mobile상단: 1행 전체 로고+메뉴, 2행 검색+최근 본+테마. 메인/랭킹/검색은 하단 고정 한 곳에만. 상세에서 하단랭킹활성, 메인에서는메인, 검색에서는검색.
- PC 본문/우측레일 폭과 시작선을 동일. 레일 최근 본은 순위처럼 번호 붙이지 않음. 목차는 실제 해당 본문 section순서.
