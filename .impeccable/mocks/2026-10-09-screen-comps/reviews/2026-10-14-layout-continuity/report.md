## 디자인 고유성과 전체 인상

B ‘대회 기록실’은 흰 읽기 표면, 진한 데이터 글자, 빨강·금색 브랜드, 순위 색, 기록표의 선으로 금융 정보의 명확성과 CD의 대회 성격을 함께 표현한다. 이 방향은 유지할 가치가 있다. 문제는 브랜드의 차분함이나 재미의 양보다 **같은 역할의 요소가 화면마다 서로 다른 깊이에 들어가 있는 것**이다.

06에서는 기업 페이지 메뉴 안에 대상 선택이 있는 것처럼 읽히지만, 07에서는 대상 선택 아래에 페이지 메뉴가 놓인다. 사용자는 기업/종목 선택과 기본정보/지표 선택의 관계를 매번 새로 해석해야 한다. 시안들을 별도로 그리면서 공통 화면 규칙이 유지되지 않은 결과로 보인다.

## 확보된 강점

1. 흰 바탕·기록표·빨강과 금색은 CD의 고유한 읽기 경험을 만들 재료다. 일반 금융 대시보드로 바꿀 필요는 없다.
2. 05–08은 기업 합산과 실제 구성 종목을 상단에서 보여주고, 예시 **549조=495조+54조**와 세 시총 선으로 같은 기업 안의 탐색 이유를 만든다.
3. 현재값·과거 기록·미제공·마지막 제공값과 금융 단위를 구분하는 표현이 있다. BPS·DPS 등 데이터의 성격에 따른 분석 차이를 유지할 수 있다.

예시 숫자는 시안용이며 현재 시장 데이터가 아니다.

## 우선 문제 5개

### P1 · 상세 화면의 상위·하위 관계가 뒤집힌다

**근거:** 위 표의 05–08 순서. 12는 현재값 아래 지표 메뉴가 있고, 14는 선택한 DPS를 탭 맨 앞으로 옮긴다.

**영향:** 대상과 정보 종류의 관계를 다시 해석해야 한다. 학습한 위치를 다음 화면에서 활용할 수 없다.

**수정 규칙:** 모든 상세에서 **이름·종류·코드·기준일 → 기업·구성 종목 선택 → 고정 순서 페이지 메뉴 → 현재값 → 본문**. 선택된 지표도 원래 자리를 유지한다. 05의 대상 버튼은 ‘기업 합산 시총’ 대신 ‘기업 전체(합산)’로 표시하여 대상과 페이지 이름을 분리한다.

관련 명령: `$impeccable layout`, `$impeccable clarify`.

### P1 · 종목을 바꾸는 흐름과 지표를 바꾸는 흐름이 이어지지 않는다

**근거:** 08의 상단 대상 선택기가 09–14에서 사라지고 예시도 삼성전자에서 SK하이닉스로 바뀐다. 06에서 구성 종목을 눌러 07 기본정보로 착지한다고 가정하면 시총 비교 맥락이 끊긴다. 이미지로 실제 링크 목적지를 검증한 것은 아니다.

**수정 규칙:**
- 06 기업 합산 시총 → 구성 종목 선택 → 08 해당 종목 시총.
- 08 또는 09–14에서 다른 구성 종목 선택 → 같은 지표 유지.
- 지표 선택 → 같은 종목 유지.
- 05·07 기본정보에서 대상 선택 → 기본정보 맥락 유지.
- 어디서든 기업 합산 선택 → 06 기업 합산 시총으로 명시적으로 이동. 기업 PER는 만들지 않는다.
- 연결 시안은 같은 예시 기업으로 통일하되 실제 존재하는 구성 종목만 사용한다.
- 기간·기준일 유지와 뒤로가기 시 순위 조건/스크롤 복원은 후속 구현 검증 항목이다. 이미지로 보장하지 않는다.

관련 명령: `$impeccable shape`, `$impeccable clarify`.

### P2 · 서비스 외곽과 보조 영역의 역할이 달라진다

**근거:** 06·07·08 모바일 전역 탐색 위치가 다르고 PC 레일의 시작선과 목차 의미가 다르다. 07 ‘페이지 안내’는 본문 목차가 아니라 이미 상단에 있는 지표 목적지를 반복한다. 16에서는 랭킹·상세 상태에도 메인 활성 표시가 사용된다.

**수정 규칙:** PC는 공통 헤더 아래 동일한 본문/보조 영역 폭과 시작선을 둔다. 대상 선택·페이지 메뉴는 주본문의 맥락 영역에 속한다. 레일의 ‘이 페이지 내용’은 실제 본문 절 순서만 따른다. 모바일은 브랜드·검색의 상단과 메인/랭킹/검색의 고정 하단 탐색을 일관되게 사용한다. 최근 본·테마·메뉴의 진입점도 고정한다. 오류·로딩은 해당 본문 영역을 대체하며 현재 위치를 바꾸지 않는다.

관련 명령: `$impeccable layout`, `$impeccable adapt`.

### P2 · 조회 범위와 이동 후의 조건이 불명확하다

**근거:** 10의 최근 3개월 차트 옆 통계에는 2025년 최고·최저가 보인다. 12의 ‘최근 연말’ 선택은 네 해 막대와 함께 쓰인다. 01의 ‘전체 2666개 기업’ 문맥에서 종목 지표로 이동하며, 02의 KOSPI+KOSDAQ과 03의 KOSPI 표기가 대상 범위 변화와 시장 변화 중 무엇인지 구분하기 어렵다.

**수정 규칙:** 기업/종목, 시장 범위, 기준일, 조회기간, 집계 단위를 분리한다. 차트와 통계가 다른 범위면 각각 명시한다. BPS 연말 기록과 현재 관측값의 구분은 유지한다. 순위에서 행을 누르면 해당 지표 상세로 연결하고 기본정보는 별도 목적지로 표시한다.

관련 명령: `$impeccable clarify`, `$impeccable shape`.

### P2 · 반복된 탐색과 불규칙한 하단 행동이 집중을 깨뜨린다

**근거:** 07은 지표 메뉴 8개, 바로가기 7개, 레일의 지표 링크를 반복한다. 같은 값이 대상 선택·비교표·기업 정보에서 재등장한다. 09–14는 기본정보 복귀, CSV, 인접 순위와 전체 순위의 위치가 다르다. 12의 ‘하단 기록 계속(CSV)’는 펼치기와 다운로드를 섞는다.

**수정 규칙:** 지표 변경은 상단 메뉴 한 곳을 주 진입점으로 삼고 중복 바로가기를 줄인다. 기본정보도 고정된 메뉴 첫 항목으로 유지한다. 분석 페이지 하단은 **연도별 기록 → 전체 이력 CSV → 계산식·자료 기준 → 같은 지표의 인접 순위/전체 순위**로 역할을 고정한다. CSV의 전체 이력 범위는 차트 기간과 별도임을 명시한다. 기본정보 페이지에 없는 기록 모듈을 억지로 추가하지 않는다.

관련 명령: `$impeccable distill`, `$impeccable layout`, `$impeccable clarify`.

모바일 대상 선택의 권장안은 ‘기업 전체 한 줄 + 실제 구성 종목 두 칸’이다. 구성 종목이 더 많은 기업은 줄바꿈 또는 명시적 펼치기를 사용하고, 없는 우선주를 만들지 않는다. 선택지가 사라지지 않도록 현재 대상만 표시하는 숨김 선택기는 우선안으로 삼지 않는다.

## 달라져야 하는 본문

- 기업 기본: 사업·기업 정보. 종목 기본: 주가·거래량·발행주식·종목 정보.
- 시총: 기업 합산·구성 종목 세 선, 관측한 구성 종목 수와 날짜 범위.
- PER: 추이·히트맵·분포. 다른 지표에 동일 분석을 억지로 복제하지 않음.
- PBR/EPS/배당수익률: 각 지표의 추이와 해당 통계.
- BPS: 연말 막대와 현재값 구분. DPS: 금액 막대와 이전 제공 기록 대비 변화율.
- 기본정보와 지표 상세의 본문 높이·모듈 수·PC 열 수는 목적에 따라 달라도 됨.

합산 시총은 현재 기업 전체와 과거의 관측 가능한 구성 종목 합계가 다를 수 있다. 미관측 값을 0으로 취급하지 않는다. 시안의 **현재 주가 차이 20,000원**은 이번 표현 제안이며, 기존의 역사적 괴리율/스프레드 서비스가 존재한다는 뜻이 아니다. 공식 기업 합산 PER도 제안하지 않는다.

## 인지 부담과 감정 흐름

정적 이미지의 인지 부담 체크: 단일 초점, 메뉴 묶음, 일관된 위계, 한 번에 한 결정, 선택의 중복 최소화, 화면 간 기억 부담에서 문제가 있다. 대상 버튼과 분석 모듈의 시각적 묶음은 비교적 명확하다. 모바일의 자세한 보조 분석을 뒤로 보내는 표현은 가능하지만 전체 전개 동작은 미검증이다.

07에는 지표 8개와 바로가기 7개가 동시에 반복된다. 개수만으로 사용성 실패를 판정하지 않는다. 문제는 같은 결정을 여러 곳에서 다시 제시하고, 화면이 바뀔 때 그 위치도 달라지는 것이다.

감정 흐름: 순위의 색과 큰 숫자가 호기심을 만들고 기업 합산 비교가 탐색 동기를 강화한다. 그러나 대상 선택을 누른 뒤 메뉴 순서와 본문 틀이 바뀌면 ‘다른 종목도 구경하는 재미’가 위치를 다시 찾는 노동으로 바뀐다. 마지막의 인접 순위와 같은 기업 비교를 안정된 자리에서 제공하면 자연스럽게 다음 탐색으로 이어질 수 있다. 이는 설계 가설이며 사용성 테스트 결과는 아니다.

- **처음 방문한 사람:** 기업 전체와 보통주/우선주, 지표의 차이를 배우는 순간 메뉴의 상위·하위까지 바뀜. 05의 ‘기업 합산 시총’ 활성은 현재 페이지가 기본정보인지 시총인지 혼동시킨다.

## 사소하지만 후속 조정이 필요한 부분

- 궁서풍 요청은 일부 시안에만 반영되었고 생성 이미지의 글자 형태다. 실제 동일 폰트 파일로 통일된 상태가 아니다.

## 자동 진단과 파일 증거

Assessment B의 1회 detector 결과는 갤러리 HTML/CSS의 advisory 10건(색상 7, 글자 크기 3)이다. 위치는 review.html:4와 detector가 0행으로 보고한 색상 2건이다. 이는 PNG 내부 화면 구조를 검사한 결과가 아니므로 위 레이아웃 문제의 자동 검증이나 반증으로 해석하지 않는다. 이번 대상은 서비스 디자인 토큰 적용 대상인 갤러리인지도 구분해야 하므로 서비스 UI의 우선 결함에 합산하지 않았다. 새 ignore 항목으로 숨기지 않았다.

선택 이미지 16/16, HTML의 src/data-source/크기 16/16, 원문 프롬프트·메타데이터·PNG 내 프롬프트 16/16이 일치한다. 15장은 1448×1086, 06은 1536×1024다. 이 파일 확인은 브라우저 렌더링 검증과 다르다.

검토는 로컬 PNG의 시각 확인, 선택 목록과 파일 검증을 사용했다. 브라우저 도구 정책이 로컬 file:// 접근을 막아 갤러리 실화면과 overlay는 확인하지 않았다. HTTP 우회나 임시 서버는 사용하지 않았다. 09–14의 선행 시각 검토는 동일한 선택 파일에 대해 재사용했다. 제품 코드·갤러리·PNG는 이번 검토에서 수정하지 않았다.
