# B 대회 기록실 · 화면별 이미지 시안

2026-10-09~10 · 사용자 검토용. 제품 코드 구현이나 승인 완료를 의미하지 않는다.

모든 수치는 예시이며, 기업 합산과 개별 종목·지표의 맥락을 구별한다. 내장 imagegen으로 각 화면을 생성했다. 현재 사용자 컨펌 대기다. 선택된 B 이미지를 공통 시각 참고로 사용한다.

생성 대상은 메인, 기업/종목 시총 랭킹, 6개 지표 랭킹 변형, 기업/종목 기본과 시총 상세, 6개 지표별 상세, 검색/최근 본/메뉴, 주요 상태다. 일반 화면은 데스크톱·모바일을 함께 보여주며 지표별 랭킹 변형과 주요 상태는 별도 시트로 모은다. 첫 라이트 시안이며 다크의 전체 변형은 이번 묶음에 포함하지 않는다.

각 PNG의 JSON에 도구에 전달한 정확한 프롬프트와 참고 이미지 경로를 보존한다. 화면별 실제 경로와 검토 순서는 review.md에서 확인한다.
