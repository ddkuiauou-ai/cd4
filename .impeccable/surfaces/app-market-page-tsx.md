# 랭킹: 지표부터 전체 순위까지

Scope: `/`와 기업 합산·종목별 시가총액 및 PER/PBR/EPS/BPS/배당수익률/주당배당금의 전체 순위·페이지. Visitor mode: Operate. 현재 계약은 [PRODUCT](../../PRODUCT.md), [DESIGN](../../DESIGN.md)이며 상세·대시보드·공통 헤더의 별도 규칙을 덮지 않는다.

THESIS: 모든 본문 폭에서 순위·종목·지표·주가의 읽기 축을 유지하며 남는 공간을 차트에 배분한다. 전체 순위에서 상세와 CSV로 이어지고 하단에서는 자료 기준과 다음 지표를 찾는다.

OWN-WORLD: B 대회 기록실의 조선궁서 400, 원본 별, 빨강·금색 브랜드, 흰 읽기 표면과 다크 토큰을 사용한다. 상위 세 순위의 식별색과 순위 이동·가격 등락을 구분한다. 순위 이동과 주가 방향은 각각 계산하며 상승 빨강·하락 파랑·유지 중립색이다.

STORY: 집계 단위와 지표가 드러나는 제목·시장·공개 기준일·CSV → ‘시가총액’ 묶음 안의 ‘기업 합산’·‘종목별’ 링크와 묶음 밖의 여섯 지표 링크 → 한 벌의 순위표 → 페이지 이동 → 전체 폭 자료 안내 → 데스크탑 콘텐츠 목차. 여덟 순위 링크는 한 줄을 유지하며 메뉴가 넘치면 현재 선택을 드러낸다. 기업명은 합산 상세, 실제 종목은 해당 종목 상세로 이동한다.

RESPONSIVE: 랭킹 본문의 실제 폭을 따른다. 680px를 넘으면 순위·식별·지표값을 가까이 두고 종가와 전일 등락률의 읽기 폭을 확보한 뒤 추이를 최대 450px까지 넓힌다. 680px 이하는 종목 정보 아래에서 지표값과 단위를 읽고, 오른쪽에 종가·추이·전일 등락률을 쌓는다. 전체 폭에서 한 표를 유지하며 순위·이동량은 하나의 중심축에 둔다.

QUOTE: 정확한 십진 계산에서 얻은 좌표·날짜 간격·결측 구간·단일 관측점을 유지한다. 종가·전일 등락률과 선은 독립된 공간에 배치한다. 초기 HTML에 선을 포함하고 차트 크기가 바뀌면 선과 14px 끝점의 좌표를 갱신한다. 최신 가격 결측·화면 밖 정지·동작 줄이기 규칙을 유지한다.

ENDING: 마지막 순위 행 바로 아래에서 순위 범위, 전체 대상 수, 페이지 번호와 이동을 보여준다. 248px 레일은 폭 1280px 이상에서 표시하고, 높이 600px 이상이면 목록·페이지 이동 영역 안에 고정한다. 최근 본 미리보기는 [공통 동작](../../DESIGN.md#search-recent-and-theme)을 따른다. 그 아래 전체 폭에서 조회 기준과 자료 공개 정보를 기본으로 접어 둔다. 기업 합산 시총의 합산 범위와 대표 보통주 가격 기준은 항상 보인다. [공통 푸터](../../DESIGN.md#global-footer)의 오른쪽 링크는 현재 범위를 유지하며 상단 지표 메뉴로 돌아간다.

DATA: 화면 기준일은 공개 순위의 날짜를 사용한다. 순위와 지표값은 각각 고정 텍스트로 표시하고, 정확한 원값·날짜·revision은 기존 전체 순위 CSV와 데이터 계약에 보존한다. 합산 자료 부족·공개/0건/갱신 상태, 첫 20행과 다음 100행, 공식 순서·상세 링크·페이지 계약을 유지한다.
