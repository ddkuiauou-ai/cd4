# 기업·종목 상세

방문자 모드는 Operate다. 기업·종목 기본 정보, 기업 합산·종목 시가총액, PER·PBR·EPS·BPS·배당수익률·주당배당금의 10개 상세 화면에 적용한다. 2026-11-20에 승인한 삼성전자 상세 시안 `samsung-detail-study.html`의 `companyView`, `detailContent`, `order`를 제품의 실제 경로와 기존 구성 요소에 적용한다. [제품 범위](../../PRODUCT.md), [상세 탐색](../../DESIGN.md#detail-navigation), [CSV 공통 규칙](../../DESIGN.md#buttons-and-csv)을 함께 읽는다.

현재 숫자와 기준일을 먼저 읽고 각 지표에서 자주 보는 실제 기록에 곧바로 도달한다. 기존 차트·분포·표·통계·기간 선택·CSV를 재사용한다. 시안의 삼성전자 전용 라벨, 자료, 모의 로딩과 CSV 미리보기는 시안 확인용이다. 실제 구성과 제공 자료를 기준으로 모든 종목에서 일반화한다.

## 폭별 탐색

- 1280px 이상은 왼쪽 지표 이동, 본문, 오른쪽 최근 본 전체 목록과 본문 목차를 제공한다.
- 768–1279px는 왼쪽 지표 이동과 본문을 유지한다. 최근 본은 헤더에서 열고 본문 요약 다음에 목차를 둔다.
- 768px 미만은 지표 링크를 본문 위에서 줄바꿈하고 목차는 요약 다음에 둔다. 헤더 최근 본과 하단 메인·랭킹·검색을 유지한다.

기업 정보의 구성 종목 표는 실제 종목의 시총 및 주가 상세로 연결한다. 개별 종목 주가 블록은 최근 3개월이 기본이다. 기본 정보의 거래 정보는 제공되는 시가·고가·저가·거래량·발행주식·종목코드를 사용한다. 연도별 종가는 실제 마지막 거래일과 보고한다. 비교할 둘 이상의 종목이 없을 때는 실제 종목 정보가 있는 만큼 표시하고 차이 행과 비교 추이의 조건을 지킨다.

## 기간과 관측

- PER·PBR·EPS·배당수익률 추이는 최근 5년이 기본이다. 월 단위로 표시하는 추이와 월별 기록은 해당 월의 마지막 실제 제공 관측을 사용한다. BPS 추이와 PBR의 연말 BPS는 최근 5개 연말을 기본으로 실제 연말 기록을 표시한다. 주당배당금의 선택 종목 추이는 최근 12개월이 기본이다. 비교 추이·분포·연도별 표의 표본은 각 블록에 밝힌다. 차트에서는 미리 정한 기간을 선택한다. 시작일·종료일 직접 입력 폼은 두지 않는다. 기존 링크의 유효한 `start/end`는 해당 범위를 반영하고 기본 범위로 돌아가는 링크를 표시한다.
- 현재값의 공개 기준·지표 관측일·거래일·순위 기준일을 구분한다. PER/PBR의 1년 전 비교는 실제 기준일을 붙이고 같은 날에 확인된 PER/EPS/종가 또는 PBR/BPS/종가를 사용한다. 구성 종목의 차이 행도 해당 열의 동시 관측이 확인되는 값으로 계산한다. 비교 일자와 표본이 맞지 않는 경우 비교값은 결측으로 표시한다.
- PER 분포는 실제 관측의 범위와 개수를 표시하고 현재 PER 이하 관측의 비율을 함께 표시한다. 기간 평균은 해당 표본의 실제 관측을 사용한다. 실제 배당 0과 음수는 보존하고, 유효하지 않은 비교 분모·미관측에서 변화율을 계산하지 않는다. 연중과 연말을 구분하고 희소 관측과 정상 빈 기간을 드러낸다.
- 기업 합산 공개값·구성 비중과 과거 등록 종목 합계의 범위를 구분한다. 현재 화면과 다운로드는 [저장·조회 계약](../../docs/rules/data-temporal.md#보존할-저장조회-계약) 및 [상장 기간 계약](../../docs/security-lifecycle-contract-2026-10-13.md#웹-조회)을 사용한다.

## 다운로드와 검수

- 기업 정보의 구성 종목 표와 두 배당 화면의 구성 종목 표에는 해당 비교표 CSV를 붙인다. 이름, 열, 행, 순서, 표시된 차이의 범위가 표와 일치해야 한다. 비교 표의 단위와 정밀도를 보존한다.
- 해당 상세의 전체 이력 CSV는 현재 기업 또는 종목, 지표와 선택 상장기의 전체 관측을 내보낸다. 차트의 기본 기간이나 `start/end`가 파일의 시작과 끝을 바꾸지 않는다. 주가 이력은 제공되는 실제 거래일·시가·고가·저가·종가·거래량을 사용한다. 시장 전체 순위 CSV는 상세에서 제공하지 않고 기존 랭킹으로 연결한다.
- [서버 모드와 정적 출력](../../docs/rules/app-server.md#출력-모드)에서 같은 링크·제공 상태·값·비교표·다운로드를 대조한다. 기본 구간 밖에 제공 관측이 있는 표본으로 전체 이력 CSV를 확인하고, 과거 상장기 경계와 비교표 행·열, 0·음수·결측·큰 수·코드의 앞자리 0을 검수한다.
- 좁은 모바일과 넓은 PC, 두 테마에서 화면 순서와 실제 링크·목차·최근 본·다운로드를 확인한다. 보통주에 PER이 있고 우선주에 없는 표본으로 종목별 메뉴, 다른 종목을 명시한 링크, 기존 우선주 PER 주소의 정상 안내를 대조한다. 로딩·오류·빈 기간과 정상 미제공을 따로 확인한다.
