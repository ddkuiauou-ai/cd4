# 기업·종목 상세

방문자 모드는 Operate다. 이 문서는 기업·종목 상세 10개 경로의 콘텐츠 순서, 종목별 제공 조건과 다운로드 범위를 정의한다. 시각 위계와 컴포넌트 표현은 [상세 대표값과 단위](../../DESIGN.md#상세-대표값과-단위), [재무·배당 지표 상세](../../DESIGN.md#재무배당-지표-상세), [상세 탐색](../../DESIGN.md#detail-navigation)을 따른다.

**2026-11-21 인수인계.** 재무·배당 6개 화면과 기업·종목 시가총액 2개 화면에 새 구성을 적용했다. 기업 개요와 주가·거래는 메뉴명과 경로가 반영됐다. 기업 규모에서 구성 종목으로 이어지는 개요 배치와 종목 카드로 주가·거래량을 바꾸는 배치는 모바일·데스크톱 시안 단계다. 아래 두 기본 화면의 행은 현재 구현을 설명한다.

## 폭별 탐색

- [상세 탐색](../../DESIGN.md#detail-navigation)의 폭별 배치를 사용한다. 동일 지표를 제공하는 구성 종목이 둘 이상이면 본문과 우측 레일의 목적지는 같다. 종목은 `securityId`로 구분하고, URL의 선택 종목과 읽던 구간을 복원한다.
- 배당 카드는 선택 종목의 배당 지표를 강조하고 종가에서 해당 종목의 주가·거래로 연결한다. 우선주와 유일한 보통주의 차이는 각 열에서 같은 날의 값으로 계산한다. 종목을 바꿔도 비교 방향은 우선주 − 보통주로 유지한다. 범례에는 선택 종목과 마지막 표시 월의 값을 둔다.

## 화면별 기본 펼침

각 행의 요약은 첫 화면에서 제공하고 주요 기록은 표에 적힌 순서로 처음부터 펼친다. 목차는 실제 표시되는 기록을 본문 순서로 가리킨다. 상장 이력은 주가·거래에서 제공한다. 과거 상장기와 현재값 미제공은 해당 값 가까이 안내한다. 반복되는 계산식·자료 갱신번호·공개 기준일은 생략한다. 인접 순위는 같은 지표의 공개 순위에 근거해 제공한다.

- PER·PBR 추이의 월간 점은 월별 마지막 제공값, 연간 점은 그해 제공 관측의 산술평균이다. 연도별 표는 각 연도의 마지막 관측값을 쓴다. EPS에는 연중 관측이 포함되고 BPS 연말 표본에는 12월 마지막 관측만 들어간다. BPS의 현재 공개값, 선택 연말값, 기간 평균의 원천 관측을 구분한다.
- 배당 연도별 표는 선택 종목의 전년 대비 변화율(%)과 최근 5년 비교 자료의 동일 관측일 차이(원·%p)를 구분한다. 비교 범위는 제목 옆 도움말에 한 번 표시한다. 한 종목만 있으면 해당 종목의 기록을 제공한다.
- 시가총액은 카드에서 선택한 기업 또는 종목의 추이와 연도별 기록을 먼저 제공한다. 공식 구성 전체와 총액이 같은 날 일치할 때만 비중을 표시한다. 종목별 장기 비교는 등록된 종목과 날짜별 합계를, 기업 연도별 표는 실제 관측 종목 수도 표시한다.

## 기간과 관측

- PER·PBR·EPS·배당수익률 추이는 최근 5년이 기본이다. 월 단위로 표시하는 추이와 월별 기록은 해당 월의 마지막 실제 제공 관측을 사용한다. BPS 추이와 PBR의 연말 BPS는 최근 5개 연말을 기본으로 실제 연말 기록을 표시한다. 주당배당금의 선택 종목 추이는 최근 12개월이 기본이다. 비교 추이·분포·연도별 표의 표본은 각 블록에 밝힌다. 차트에서는 미리 정한 기간을 선택한다. 시작일·종료일 직접 입력 폼은 두지 않는다. 기존 링크의 유효한 `start/end`는 해당 범위를 반영하고 기본 범위로 돌아가는 링크를 표시한다.
- 현재값의 공개 기준·지표 관측일·거래일·순위 기준일을 구분한다. PER/PBR의 1년 전 비교는 실제 기준일을 붙이고 같은 날에 확인된 PER/EPS/종가 또는 PBR/BPS/종가를 사용한다. 구성 종목의 차이 행도 해당 열의 동시 관측이 확인되는 값으로 계산한다. 비교 일자와 표본이 맞지 않는 경우 비교값은 결측으로 표시한다.
- PER 분포는 실제 관측의 범위와 개수를 표시하고 현재 PER 이하 관측의 비율을 함께 표시한다. 기간 평균은 해당 표본의 실제 관측을 사용한다. 실제 배당 0과 음수는 보존하고, 유효하지 않은 비교 분모·미관측에서 변화율을 계산하지 않는다. 연중과 연말을 구분하고 희소 관측과 정상 빈 기간을 드러낸다.
- 기업 합산 공개값·구성 비중과 과거 등록 종목 합계의 범위를 구분한다. 현재 화면과 다운로드는 [저장·조회 계약](../../docs/rules/data-temporal.md#보존할-저장조회-계약) 및 [상장 기간 계약](../../docs/security-lifecycle-contract-2026-10-13.md#웹-조회)을 사용한다.

## 다운로드와 검수

- 기업 개요의 구성 종목 표와 두 배당 화면의 구성 종목 표에는 해당 비교표 CSV를 붙인다. 이름, 열, 행, 순서, 표시된 차이의 범위가 표와 일치해야 한다. 비교 표의 단위와 정밀도를 보존한다.
- 전체 이력 CSV는 고정 제목의 링크 복사·공유하기 옆에 둔다. 좁은 폭에서는 제목과 작업이 두 줄로 배치될 수 있다. 해당 상세의 전체 이력 CSV는 현재 기업 또는 종목, 지표와 선택 상장기의 전체 관측을 내보낸다. 차트의 기본 기간이나 `start/end`가 파일의 시작과 끝을 바꾸지 않는다. 주가 이력은 제공되는 실제 거래일·시가·고가·저가·종가·거래량을 사용한다. 시장 전체 순위 CSV는 상세에서 제공하지 않고 기존 랭킹으로 연결한다.
- [서버 모드와 정적 출력](../../docs/rules/app-server.md#출력-모드)에서 같은 링크·제공 상태·값·비교표·다운로드를 대조한다. 기본 구간 밖에 제공 관측이 있는 표본으로 전체 이력 CSV를 확인하고, 과거 상장기 경계와 비교표 행·열, 0·음수·결측·큰 수·코드의 앞자리 0을 검수한다.
- 좁은 모바일과 넓은 PC, 두 테마에서 화면 순서와 실제 링크·목차·최근 본·다운로드를 확인한다. 보통주에 PER이 있고 우선주에 없는 표본으로 종목별 메뉴, 다른 종목을 명시한 링크, 기존 우선주 PER 주소의 정상 안내를 대조한다. 로딩·오류·빈 기간과 정상 미제공을 따로 확인한다.
- 390·808·1440px에서 대표값·순위, 제목 작업과 첫 차트의 정렬을 확인한다. 합산 → 우선주 카드 → 우선주 연도별 기록 → 합산을 따라가고 첫 응답 및 이력 로딩을 완료 화면과 대조한다. 배당수익률의 연도·관측일, %와 %p, 예외 사유 도움말을 확인한다. BPS는 현재값과 연말값이 서로 다른 표본을 사용한다.
