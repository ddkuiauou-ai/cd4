# 기업·종목 상세

방문자 모드는 Operate다. 아래 표는 기업 2개·종목 7개 공개 경로의 콘텐츠 순서, 제공 조건과 다운로드 범위를 정의한다. 대표 숫자·단위는 [상세 대표값과 단위](../../DESIGN.md#상세-대표값과-단위), 기록 표는 [연도별 기록](../../DESIGN.md#연도별-기록)을 따른다.

## 폭별 탐색

- 왼쪽 지표 메뉴, 요약 아래 목차, 고정 제목과 우측 레일은 [상세 탐색](../../DESIGN.md#detail-navigation)의 폭별 배치를 사용한다. 실제 구성 종목은 `securityId`로 구별하고 전환 후 URL의 종목·상장기와 읽던 구간을 복원한다.
- 시총의 합산·종목 전환은 [시가총액 상세](../../DESIGN.md#시가총액-상세)를 따른다. 주가·거래량의 진입점은 해당 시가총액 상세의 `#price-history`다.
- 배당 비교 카드와 우측 종목 목록은 같은 지표의 해당 종목을 연다. 현재·1년 전 비교는 선택 종목을 기준으로 읽으며, 연도별 비교 열은 우선주 − 보통주 방향이다. [재무·배당 지표 상세](../../DESIGN.md#재무배당-지표-상세)

## 화면별 기본 펼침

각 행의 요약은 첫 화면에서 제공하고 주요 기록은 표에 적힌 순서로 처음부터 펼친다. 목차는 실제 표시되는 기록을 본문 순서로 가리킨다. 상장 이력의 표시 조건은 [상세 탐색](../../DESIGN.md#detail-navigation)을 따른다. 과거 상장기와 현재값 미제공은 해당 값 가까이 안내한다. 반복되는 계산식·자료 갱신번호·공개 기준일은 생략한다. 인접 순위는 같은 지표의 공개 순위에 근거해 제공한다.

- PER·PBR 추이의 월간 점은 월별 마지막 제공값, 연간 점은 그해 제공 관측의 산술평균이다. 연도별 표는 각 연도의 마지막 관측값을 쓴다. EPS에는 연중 관측이 포함되고 BPS 연말 표본에는 12월 마지막 관측만 들어간다. BPS의 현재 공개값, 선택 연말값, 기간 평균의 원천 관측을 구분한다.
- 재무·배당 여섯 지표의 헤더·순위·관측일 배치는 [재무·배당 지표 상세](../../DESIGN.md#재무배당-지표-상세)를 따른다. EPS·BPS는 PER과 같은 현재·1년 전 비교 배치에서 실제 주당 지표를 보여준다. 각 분수는 같은 날짜와 표시 정밀도로 검증한 경우에 표시한다.
- 배당 연도별 표는 선택 종목의 전년 대비 변화율(%)과 최근 5년 비교 자료의 동일 관측일 차이(원·%p)를 구분한다. 비교 범위는 제목 옆 도움말에 한 번 표시한다. 한 종목만 있으면 해당 종목의 기록을 제공한다.
- 구성 종목이 둘 이상인 경우 합산과 모든 구성 종목의 시가총액을 한 차트에 그리고 선택선을 강조한다. 합산선은 부분 관측일에 비워 두며, 도움말에 실제 관측 종목 수와 부분합을 보여준다. 단일 종목은 선 하나를 표시한다. 공식 구성 전체와 총액이 같은 날 일치할 때 비중을 표시한다.

## 기간과 관측

- PER·PBR·EPS·배당수익률 추이는 최근 5년이 기본이다. 월 단위로 표시하는 추이와 월별 기록은 해당 월의 마지막 실제 제공 관측을 사용한다. BPS 추이와 PBR의 연말 BPS는 최근 5개 연말을 기본으로 실제 연말 기록을 표시한다. 주당배당금의 선택 종목 추이는 최근 12개월이 기본이다. 비교 추이·분포·연도별 표의 표본은 각 블록에 밝힌다. 차트에서는 미리 정한 기간을 선택한다. 시작일·종료일 직접 입력 폼은 두지 않는다. 기존 링크의 유효한 `start/end`는 해당 범위를 반영하고 기본 범위로 돌아가는 링크를 표시한다.
- 시총 차트는 5년, 주가·거래량 차트는 최근 3개월이 기본이다. 두 기간은 URL에서 각각 복원하며, 최근 3개월·1년·5년·전체를 선택할 수 있다. 대상 전환은 두 기간과 현재 구간을 이어 본다.
- 현재값의 공개 기준·지표 관측일·거래일·순위 기준일을 구분한다. PER/PBR의 1년 전 비교는 실제 기준일을 붙이고 같은 날에 확인된 PER/EPS/종가 또는 PBR/BPS/종가를 사용한다. 구성 종목의 차이 행도 해당 열의 동시 관측이 확인되는 값으로 계산한다. 비교 일자와 표본이 맞지 않는 경우 비교값은 결측으로 표시한다.
- PER 분포는 실제 관측의 범위와 개수를 표시하고 현재 PER 이하 관측의 비율을 함께 표시한다. 기간 평균은 해당 표본의 실제 관측을 사용한다. 실제 배당 0과 음수는 보존하고, 유효하지 않은 비교 분모·미관측에서 변화율을 계산하지 않는다. 연중과 연말을 구분하고 희소 관측과 정상 빈 기간을 드러낸다.
- 기업 합산 공개값·구성 비중과 과거 등록 종목 합계의 범위를 구분한다. 현재 화면과 다운로드는 [저장·조회 계약](../../docs/rules/data-temporal.md#보존할-저장조회-계약) 및 [상장 기간 계약](../../docs/security-lifecycle-contract-2026-10-13.md#웹-조회)을 사용한다.

## 다운로드와 검수

- 기업 개요의 구성 종목 비교표와 두 배당 화면의 종목 비교 영역에는 각각 비교표 CSV를 붙인다. 이름, 열, 행, 순서, 표시된 차이의 범위가 표와 일치해야 한다. 비교 표의 단위와 정밀도를 보존한다.
- 전체 지표 이력 CSV는 고정 제목의 링크 복사·공유하기 옆에 둔다. 시가총액 상세의 주가 CSV는 주가·거래량 구간에 따로 둔다. 파일은 선택 기업이나 종목, 상장기의 전체 관측을 내보낸다. 차트 기본 기간과 `start/end`는 파일 범위에 영향을 주지 않는다. 주가 이력은 실제 거래일·시가·고가·저가·종가·거래량을 사용한다. 시장 전체 순위 CSV는 기존 랭킹에서 제공한다.
- [서버 모드와 정적 출력](../../docs/rules/app-server.md#출력-모드)에서 같은 링크·제공 상태·값·비교표·다운로드를 대조한다. 기본 구간 밖에 제공 관측이 있는 표본으로 전체 이력 CSV를 확인하고, 과거 상장기 경계와 비교표 행·열, 0·음수·결측·큰 수·코드의 앞자리 0을 검수한다.
- 좁은 모바일과 넓은 PC, 두 테마에서 화면 순서와 실제 링크·목차·최근 본·다운로드를 확인한다. 보통주에 PER이 있고 우선주에 없는 표본으로 종목별 메뉴, 다른 종목을 명시한 링크, 기존 우선주 PER 주소의 정상 안내를 대조한다. 로딩·오류·빈 기간과 정상 미제공을 따로 확인한다.
- 390·808·1440px에서 대표값·순위, 제목 작업과 첫 차트의 정렬을 확인한다. 합산 → 우선주 행 → 우선주 연도별 기록 → 합산을 따라가고 첫 응답 및 이력 로딩을 완료 화면과 대조한다. 배당수익률의 연도·관측일, %와 %p, 예외 사유 도움말을 확인한다. BPS는 현재값과 연말값이 서로 다른 표본을 사용한다.
