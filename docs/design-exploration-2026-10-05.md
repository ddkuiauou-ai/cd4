# 천하제일 단타대회 디자인 탐색

2026-10-05 · 현황 조사와 선택 전 시안. 실제 화면의 리디자인 구현은 아직 진행하지 않았다.

## 사용자와 목적

사용자가 확인한 우선 장면은 개인 투자자의 모바일 조회다. 검색에서 바로 PER 같은 지표를 확인하고, 일부 상위 종목에 그치지 않고 전체를 줄 세워 탐색하며, 엑셀에서 사용할 데이터를 내려받는 것이 핵심이다. SEO를 통해 유입을 만들고 다른 서비스로 확장하는 기반을 지향한다. 엔터테인먼트 성격도 중요한 제품 자산이다.

이름 ‘천하제일 단타대회’, 레트로 별 아이콘, 황금 노랑과 붉은색의 브랜드는 유지한다. 사용자는 먼저 이미지 시안을 비교하고 선택한 이미지를 기준으로 구현하는 작업 방식을 선택했다.

## 확인 범위

- 로컬 실행 화면: 홈의 데스크톱·390px 모바일, 삼성전자 기업 시가총액 상세의 데스크톱.
- 소스: 글로벌 토큰, 헤더·모바일 메뉴, 검색, 랭킹·다운로드·기업 및 종목 상세·차트.
- 독립 조사: 사용 흐름과 정보 구조, 브랜드 자산과 시각 규칙을 나눠 검토했다.
- 실제 운영 유입·SEO 성과·모바일 사용자 행동 데이터는 이번 조사 대상이 아니다.

## 현재 디자인의 핵심 문제

브랜드는 이미 개성이 있지만 제품 UI에 일관된 규칙이 없다. 현재 헤더는 원본 벡터 워드마크 대신 시스템 serif와 CSS 외곽선으로 이름을 만든다. 실제 원본 public/logo_long.svg, public/logo_short.svg를 재평가할 가치가 있다.

브랜드의 노랑·빨강, 지표 의미의 상승·하락, 조작 강조·오류 색이 섞여 있다. 카드마다 그라데이션·색면·그림자·아이콘 강조가 달라 ‘레트로 시대감’보다 컴포넌트의 누적이 눈에 들어온다. 금융 데이터의 양수·음수·중립과 브랜드 강조는 독립 토큰으로 관리해야 한다.

데스크톱 홈은 큰 행과 차트로 첫 화면에서 비교할 수 있는 기업 수가 적다. 모바일에서는 긴 기업명·시총·등락·차트가 좁은 한 줄에서 경쟁한다. 상세에서는 제목·소개·설명·색 카드가 첫 화면 대부분을 차지하고 핵심 지표 전환은 아래쪽에 있다.

## 유지할 기능

검색 명령창과 단축키, 순위 변화, 작은 추이 차트, 기간·지표 선택, 보통주·우선주 비교와 차트 연동, 최근 본, 공유, CSV 다운로드. 대회 참가·게임 점수·포트폴리오·매매 기능을 새로 도입하지 않는다.

## 공통 UX 방향

첫 화면은 이름 → 검색 → 지표 선택 → 해당 지표의 전체 순위로 이어진다. 큰 홍보 영역 대신 실제 숫자가 주도한다. 한 종목에 하나의 읽기 순서를 주고 회사명과 대표 수치가 먼저, 코드와 작은 차트는 다음에 온다. 데이터 기준일·단위·합산 범위를 표 가까이 둔다.

CSV는 ‘엑셀에서 열 수 있는 CSV’로 안내한다. XLSX 지원, 전체 랭킹 일괄 다운로드, 사용자가 현재 보고 있는 범위와 다운로드 범위는 후속 구현에서 결정한다. 다운로드 액션은 표 위에서 쉽게 찾을 수 있게 한다.

SEO를 위한 각 지표 페이지는 독립적인 제목·짧은 설명·읽을 수 있는 순위 본문과 링크를 갖춘다. 전체 랭킹 탐색은 사용자와 검색 엔진 모두에게 명확한 페이지 경로를 제공해야 한다. 끝없는 클라이언트 스크롤만으로 모든 종목을 숨기지 않는 방향을 검토한다.

브랜드의 재미는 워드마크, 별 배지, 선택한 지표의 반응, 순위 변화의 작은 움직임에 집중한다. 읽는 중에는 표가 안정적으로 머문다. 데이터 수치·시장 상승하락 색과 브랜드 색의 역할을 분리한다.

표준적인 밝은 조회 UI도 선택 화면에 보조안으로 제공한다. 이 안은 친숙하지만 고유한 개성은 가장 적다.
