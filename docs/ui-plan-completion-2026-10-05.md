# 상세 미달 항목 후속 구현

2026-10-05 · 사용자 요청: “덜 구현된 부분 추가로 구현계획 참조해서 구현해 보자”.

**이번 범위의 R1–R5는 수정·검증했다.** [이전 인수 기준 점검](./ui-plan-acceptance-check-2026-10-05.md)의 발견 기록은 당시 상태로 보존한다. 전체 정적 export와 실제 OS·글자 확대 환경 등 기존 미검증 항목은 계속 남아 있으며, 사이트 전체의 인수 완료로 확대하지 않는다. 배포·커밋·데이터베이스 변경은 하지 않았다. 최종 standalone 미리보기는 3100 포트에서 실행 중이다.

## 구현 결과

| 항목 | 변경과 확인 |
| --- | --- |
| R1 · 이력 없는 유효 종목의 시총 상세 | 빈 배열·유효 이력 없음에서도 현재 snapshot, 주가·날짜, 일곱 지표, 기본 정보, 회사·종목 탐색을 유지한다. 존재하지 않는 종목만 404이며 조회 실패는 정상 빈 상태로 숨기지 않는다. 기존의 잘못된 테스트 기대를 고쳤다. |
| R2 · 변화율 비교 기준 | 시총·PER·PBR·EPS의 현재 주가는 같은 최신 가격 레코드의 저장된 `rate`를 사용하고 ‘전일 대비’로 설명한다. PER·PBR·EPS에는 가격 기준일도 값 가까이에 표시한다. 등락률이 없으면 ‘—’, 실제 0은 0.00%이며 희소한 두 가격으로 일간 변화율을 다시 만들지 않는다. |
| R2 · snapshot과 재무 평균 | 시총 snapshot의 날짜·값이 이력에서 확인되는 경우에만 그 날짜 이전의 최근 기록과 비교하며 실제 비교 날짜를 붙인다. 근거가 없으면 ‘—’다. PER·PBR·EPS의 각 변화율에는 실제 분모인 12개월/3년/5년/10년/20년 평균 라벨을 붙였다. 기존 재무 계산 공식과 평균 기간은 유지했다. |
| R3 · PBR CSV의 결측 BPS | CSV에는 원본의 null/누락을 빈 셀, 실제 0을 숫자 0으로 보존한다. 차트용 BPS 정규화 정책과 분리했으며 PBR 유효 행의 범위·순서·파일명을 유지한다. |
| R4 · 빈 상세의 공유 | 일곱 지표의 정상 빈 상세에도 동일한 단일 헤더 복사·공유 컨트롤을 제공한다. 이력이 없는 화면에 차트나 다운로드 데이터를 만들지 않는다. |
| R5 · 320px 차트 | 기업·개별 종목 시총 차트의 고정 최소 폭 300px를 제거하고 부모 폭 안에서 줄어들게 했다. 축·툴팁·이력 데이터는 유지한다. |

빈 상세에서 현재 우선주가 시총 결측 때문에 가족 조회에서 제외되는 경우도 보완했다. 현재 `securityId`를 목록에 한 번 포함해 본문과 레일에 같은 탐색을 전달한다. 회사 링크는 대표 보통주를 우선하고, 없는 경우 현재 종목 코드로 접근한다. 조회의 기존 필터·합산 정책은 바꾸지 않았다.

첫 화면 확인에서 발견한 모바일 긴 제목과 공유 버튼 겹침도 수정했다. 작은 화면에서는 지표명을 회사명 아래 줄로 두고 긴 회사명은 가용 폭 안에서 줄바꿈한다. 640px 이상은 기존 inline 제목을 유지하며 고정 버튼 크기와 헤더 높이 측정도 유지한다.

- 한국가스공사: 종목 비교와 핵심 지표 모두 **36,000원 / 전일 대비 +2.13%**. 시총 변화는 **2025-09-19 이력 대비 -0.6%**로 현재 snapshot 기준에 맞춘다. 최종 PBR 320/1440px에서도 동일 주가·가격 기준일·평균 비교 라벨을 확인했다.
- 맥쿼리인프라 빈 PBR: 실제 데이터의 빈 상세에서 일곱 지표·기본 정보·공유·복사를 확인했다. 복사된 주소는 해당 종목의 공개 canonical이다. 최종 320px에서 제목 오른쪽 끝 약 137px, 액션 시작 220px로 겹침이 없으며 복사·공유 각각 한 개, 가로 넘침 0px다.
