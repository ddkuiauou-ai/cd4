# A안 반응형 헤더 적용 · 2026-10-23

사용자가 선택한 `.impeccable/mocks/2026-10-22-header/preview.html`의 A안을 실제 공통 헤더에 적용했다. 모바일 하단 탐색은 유지하고, 기존 햄버거 메뉴의 지표별 진입은 랭킹 화면으로 통일한다. 제품 코드 적용과 아래 로컬 검증을 완료했으며 배포나 사용자 최종 수락을 의미하지 않는다.

## 구현

- 실제 DOM과 키보드 순서는 브랜드 → 검색 → 메인·랭킹 → 최근 본 → 테마다. 기존 메인 `/dashboard`와 랭킹 `/` 목적지를 유지한다.
- 360px 미만은 원본 별만, 360–959px는 천·원본 별·단, 960px 이상은 전체 이름이다. 원본 SVG와 조선궁서 400을 재사용하고 로고의 접근성 이름은 전체 이름을 유지한다.
- 헤더 내부 높이는 60/68/76px, 경계선 포함 초기 높이는 61/69/77px다. 기존 ResizeObserver를 유지해 상세 고정 제목·목차·우측 레일이 실제 높이를 계속 참조한다.
- 검색은 390px부터 짧은 문구, 520px부터 전체 안내, 640px부터 단축키를 표시한다. 최근 본은 640px부터 아이콘과 문구를 함께 표시한다. 모바일 검색·탐색·아이콘은 최소 44px 영역을 확보한다.
- 실제 검색 데이터·결과 이동·단축키·하단 검색 이벤트, 최근 기록·저장된 지표/기간 경로, 테마 저장·기기 설정을 보존했다. 시안의 임시 패널이나 예시 데이터는 사용하지 않았다.
- 검색창을 닫을 때 실제 호출 버튼으로 포커스를 복귀한다. 헤더는 클릭의 currentTarget을 기록하며, 하단 검색은 자신의 버튼에 포커스를 둔 뒤 기존 이벤트를 전달한다. CommandDialog에는 내부 콘텐츠의 onCloseAutoFocus 전달만 추가했다.
- 최근 본 패널은 헤더의 우측 여백에 맞춰 정렬하며 화면 폭 안에서 줄어든다. Escape와 바깥 클릭으로 닫고, 기록 링크를 선택하면 닫힌다. click 이벤트를 사용해 키보드·프로그램 활성화도 바깥 클릭과 동일하게 처리한다.
- 기존 하단 탐색의 위치·safe-area·본문/푸터 여백과 알림 위치를 유지했다. 기존 상세·차트 등 다른 미커밋 변경은 보존했다.
