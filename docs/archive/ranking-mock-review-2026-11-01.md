# 랭킹 반응형 시안 측정 기록 — 2026-11-01

이 기록은 제품 적용 전 독립 HTML 시안을 반복 검토한 당시의 측정이다.
Learnings L8–L10에서 상세 측정과 시안 단계 상태를 분리했다. 본문은 해당 검증 항목의 원문이며 제품 코드를 수정하지 않았다는 설명도 당시 범위를 뜻한다.
시안의 385/386·430/431·879/880/881px 경계와 82px 주가 영역은 현행 제품 사양이 아니다.
현행 배치는 [DESIGN](../../DESIGN.md), 제품 적용 결과는 [2026-11-02 반응형 랭킹 검증](../ranking-responsive-verification-2026-11-02.md)을 따른다.
재사용할 실패 원인과 다음 행동은 [Learnings L8–L10](../learnings.md#l8--반응형-시안은-중간-폭의-공간-배분부터-확인)에 남긴다.

## 원문: L8 — 반응형 시안은 중간 폭의 공간 배분부터 확인

- 검증 상태: 별도 시안에서 450–650px를 25px 간격으로 확인했다. 네 축이 유지되며 차트는
  약 148×25px에서 234×32px까지 증가했고 가로 넘침·텍스트 영역 초과가 없었다.
  320–1000px의 추가 표본, 385/386px 경계, 긴 이름·결측·네 자리 순위와 라이트/다크도 확인했다.
  제품 코드는 수정하지 않았으며 현재 시안의 사용자 수락·실제 제품 검증·배포는 별개다.
- 후속 교정·검증: 데스크톱에서 식별 열도 남는 폭을 비율로 계속 받으면 이름 뒤 여백이 커진다.
  독립 시안에서 식별·시총 열에 적정 폭과 상한을 두고 남은 폭을 차트에 배분했다.
  1000px에서 차트는 약 281×44px → 356×56px가 되었고 기존 약 83px 행 높이는 유지됐다.
  880–1000px 표본의 연속 확대, 879/880/881 경계, 300–650px 오버레이·중간 배치 보존,
  긴 이름·결측·라이트/다크의 글자 포함 여부와 선·끝점 충돌을 확인했다. 제품 코드는 수정하지 않았다.

## 원문: L9 — 넘침 검사와 실제 글자 정렬 검사를 구분

- 검증 상태: 별도 시안에서 식별 묶음을 왼쪽 정렬 grid로 바꾸고 넓은 본문에서는 차트·종가·등락률을 한 줄로 배치했다.
  320–385px 표본에서 이름·코드·시총 시작점 차이는 0px였고, 긴 이름·결측 예시와 385/386px 경계를 확인했다.
  600/650/700px의 기존 스택, 879/880/881px의 가로 전환과 1000px, 라이트/다크를 확인했다.
  제품 코드는 수정하지 않았으며 이전 L8의 박스 검사 기록을 실제 글자 정렬의 증거로 재사용하지 않는다.

## 원문: L10 — 작은 차트의 오버레이는 선분·끝점·최소 높이를 함께 확인

- 검증 상태: 300–1000px 표본과 385/386, 430/431, 879/880/881 경계, 450–650px의 25px 간격을 확인했다.
  실제 글자 정렬·선분/끝점 충돌·가로 포함 여부를 검사했고 라이트/다크, 긴 이름·네 자리 순위·결측을 확인했다.
  좁은 영역은 82px 안에서 안전 배치의 선 높이 30px를 확보했으며 브라우저 콘솔 오류·경고는 없었다.
  제품 코드는 수정하지 않았고 제품 빌드·테스트·배포는 수행하지 않았다.
