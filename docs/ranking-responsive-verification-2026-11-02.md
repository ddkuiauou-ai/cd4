## 구현과 검토

- `ServerTable`의 caption·네 열·scope/role/headers 연결을 보존하고 모바일 이중 렌더링을 제거했다.
- `RankingQuote`는 기존 정확한 십진 좌표 계산 후 화면 기하만 변환한다. 초기 HTML은 안전 배치다.
  ResizeObserver·폰트 준비·resize를 프레임 단위로 합치고 자료 변경과 unmount 때 정리한다.
- 충돌 검사는 연결 선분·고립 점·14px 끝점을 포함한다. 우측 우선·좌측 대안이 모두 막히면 중앙 안전 배치다.
  숫자 고유 폭을 이전 `left`에서 독립시켜 화면 축소 때 높이가 누적 증가하는 문제를 수정했다.
- Impeccable adapt/craft 기준과 편집 hook의 결정적 검사를 적용하고 독립 소스 검토를 받았다.
  금융 정밀도·SSR/접근성 연결·대시보드 스타일 범위·observer 정리에서 추가 수정이 필요한 발견은 없었다.
  실제 스크린리더 발화와 물리 기기의 터치 검증은 수행하지 않았다.
