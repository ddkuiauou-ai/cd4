# 기록실 09–14 지표 화면 정리 · 2026-10-22

대상은 09 PER, 10 PBR, 11 EPS, 12 BPS, 13 배당수익률(DIV), 14 주당배당금(DPS)이다. 승인된 이미지 시안의 정보 위계를 실제 화면에 적용하고, 앞서 정리한 06–08의 기업·종목 선택과 모바일 레이아웃을 이어받았다. 궁서 계열 제목과 빨강·금색 정체성은 유지했다.

## 화면과 동작

- 공통 순서는 사이트 헤더 → 경로·종목 제목 → 기업 전체와 모든 구성 종목 → 고정 순서의 8개 탭 → 현재 공개값 → 해당 지표 추이와 표시 관측 통계이다. 종목 선택과 탭을 접거나 생략하지 않는다.
- 데스크톱에서는 추이와 통계를 나란히 배치하고 모바일에서는 차트 다음에 통계를 둔다. 통계는 실제 차트에 표시한 같은 관측으로 계산하며, 월간·연간 평균이나 연말 값과 상단의 현재 공개값을 구분한다.
- PER/BPS/DPS의 월별 기록과 분포는 별도 펼침 영역으로 옮겼다. 필요한 차트만 펼칠 때 렌더링한다. 긴 월별 표는 해당 영역 안에서 가로 이동하며 페이지 전체를 밀어내지 않는다.
- 주가 이력, 조회 기간 상세 통계, 연도별 기록은 펼쳐 볼 수 있다. 같은 기업의 종목 비교를 부가 자료보다 앞에 두고, 목차 순서를 본문 순서에 맞췄다. 모바일 목차는 항목 선택 후 접히며 고정 헤더 아래로 이동한다.
- 탭 변경은 현재 종목의 상장 기간과 조회 날짜를 유지한다. 보통주·우선주 변경은 지표와 날짜를 유지하되 목적 종목의 상장 기간을 새로 해석한다. 기업 전체는 기업 합산 시가총액으로 이동하며 존재하지 않는 기업 합산 PER 등을 만들지 않는다.
- 가까운 순위 이동에도 시작일·종료일을 유지한다. 최근 본 복귀 역시 해당 종목의 해석된 상장 기간과 날짜를 복원한다.
- BPS/DPS에서 사용자가 직접 지정한 날짜가 기본 최근 연말·12개월 필터에 다시 잘리던 오류를 수정했다. 실제 0, 음수, 결측을 구분하고 지표별 단위를 유지한다.

## 실제 화면 확인

실제 클릭으로 6개 탭 순회, BPS에서 지정한 2023-01-01~2026-10-08의 DIV/DPS 유지, 보통주↔우선주, 가까운 PER 순위, 최근 본 삼성전자 복귀, 기업 합산→구성 종목 시총 이동을 확인했다. DPS 직접 지정 구간은 918개 관측을 표시해 기본 12개월로 잘리지 않았다. 우선주 PER 미제공은 0으로 바뀌지 않았다. 상세 증거는 [이동 검증 기록](../.impeccable/review/2026-10-22-metrics/navigation/report.md)에 있다.

BPS는 각 연도의 마지막 12월 관측을 사용하는 기존 기준을 유지한다. 현재 삼성전자 자료에는 월별 유효값이 있어도 마지막 12월 관측값이 결측이므로 연말 차트가 비어 있다. 이를 앞선 월의 값으로 대체하지 않고 “이 기간에 표시할 연말 BPS 제공값이 없습니다”로 안내한다. 여러 해 BPS 관측 보존은 회귀 테스트로 확인했으며, 이 실제 빈 자료에서 채워진 그래프를 검증했다고 주장하지 않는다.

## 기술 검증과 범위

- 최종 전체 회귀 테스트 **308/308 통과**, TypeScript 확인 및 프로덕션 빌드 통과. 변경 파일 ESLint와 `git diff --check` 통과.
- 레이아웃 감지 도구의 최초·최종 결과는 모두 빈 목록이다. 실제 이미지 확인을 병행했다.
- 모바일 DPS 월별 기록의 양 끝까지 가로 이동, 분포, 주가 이력 및 연도별 자료 펼침을 확인했다. PER 모바일 목차 접힘과 고정 헤더 아래 이동, BPS 안내의 데스크톱·모바일 표시를 최종 확인했다.
- IAB 검증 콘솔 오류·경고는 없었다. 독립 Chrome 검증에는 앱 스택이 없는 비동기 메시지 채널 종료 1건이 기록됐으며 원인은 확정하지 않았다. 해당 흐름의 화면·데이터 이동 실패나 DB 연결 오류는 없었다.
- 빌드의 기존 파일 추적 경고 3개는 남아 있다. 이번 확인은 로컬 프로덕션 서버와 실제 제공 자료 기준이며 정적 배포 전체 재생성이나 실기기 검증은 수행하지 않았다. 데이터·DB 설정·백엔드·시안 원본은 변경하지 않았다.
