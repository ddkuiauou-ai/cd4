# 구현 계획 인수 기준 재점검

2026-10-05 · 사용자 요청: “계획대로 다 구현한 거 맞아? 체크해보자”.

> 후속 상태: 사용자의 추가 구현 요청에 따라 아래 R1–R5를 수정했다. 현재 결과는 [후속 구현 기록](./ui-plan-completion-2026-10-05.md)을 따른다. 이 문서의 발견·열린 상태·검사 수치는 수정 전 점검의 기록으로 보존한다.

**판정: 전체 계획 충족 아님.** 메인·랭킹과 공통 셸의 주요 구조는 계획대로 구현됐지만, 상세의 빈 상태·변화율 의미·CSV 결측 보존·320px 반응형에 확인된 미달이 있다. 전체 export와 일부 실제 환경 검증도 남았다. 앞선 F1–F4 resolved 판정은 해당 네 수정에 한정되며 이번 결과와 모순되지 않는다.

이번에는 제품 코드를 수정하지 않았다. Impeccable `audit`의 코드·반응형·테마 관점으로 계획을 대조하고, 두 독립 읽기 전용 점검 결과를 소스와 기존 산출물로 확인했다. 전체 접근성·성능 측정을 새로 수행하지 않았으므로 건강 점수나 WCAG 전체 통과를 부여하지 않는다.

## 확인된 미달 5건

### R1 · P1 · 유효 종목도 시총 이력이 없으면 상세 전체가 404

- 근거: `app/security/[secCode]/marketcap/page.tsx:162`에서 종목 존재를 확인한 뒤, 207–209 및 222–224에서 이력 없음/유효 이력 없음에 `notFound()`를 호출한다.
- 계획 위반: 3단계의 “가격 없음·지표 없음에서도 탐색이 유지” 조건. 실제 없는 종목과 존재하지만 이력이 없는 종목을 구분해야 한다.
- 영향: 현재 snapshot·다른 지표·회사 합산·종목 탐색을 볼 수 없어 상세 진입이 끊긴다.
- 테스트의 빈틈: `tests/main-data-cache.test.cjs:576`은 **알려진 종목의 빈 시총 이력에서 404를 기대한다.** 이번 155개 통과에 포함됐으므로 테스트 통과가 이 기준의 충족을 뜻하지 않는다. 다른 6개 지표는 583행부터 정상 빈 화면을 기대한다.
- 귀속: 이 404 분기는 Git HEAD에도 존재한다. 이번 변경의 신규 회귀라고 단정하지 않으며, 계획에서 해결하기로 한 기존 동작의 미처리로 기록한다. 현재 한국가스공사 페이지에 이력이 없다는 뜻도 아니다.
- 처리 기준: 없는 종목은 404를 유지하고, 알려진 종목의 빈 이력에는 snapshot 요약·지표 탭·회사/종목 탐색·공유를 유지한다. 잘못된 테스트 기대도 이 계약에 맞춘다.

### R2 · P1 · 같은 주가의 서로 다른 변화율 기준이 설명되지 않음

- 실제 증거: 한국가스공사 종목 비교의 **36,000원 +2.13%**, 핵심 지표의 **36,000원 -8.4%**가 같은 페이지에 표시된다. 시총 snapshot은 2025-09-22, 주가는 2026-10-02로 개별 날짜 안내는 있다.
- 소스: `components/card-marketcap.tsx:32`는 가격 레코드의 저장된 `rate`를 표시한다. `components/key-metrics-section.tsx:275`는 최신 두 가격 레코드의 종가로 변화율을 다시 계산한다. 시총 변화율(260행)도 최신 두 이력 레코드 기준인데 현재 snapshot 옆에 표시된다(425행).
- 계획 위반: 3·4단계의 현재값과 기준일이 설명 없이 어긋나지 않도록 하는 계약. 최신 두 기록이 인접 거래일인지, 이력 비교인지, 저장된 일간 변화율인지 UI에 구분되지 않는다.
- 영향: 사용자가 같은 가격이 동시에 상승·하락했다고 읽을 수 있다. 어느 수치의 산술이 틀렸다고 판정한 것은 아니다.
- 귀속: 두 레코드 비교 방식은 기존 HEAD에도 있었다. 기존 계산을 바꾸라는 판단이 아니라, 이번 상세 통합에서 비교 기준을 명확히 설명하지 못한 미달이다.
- 처리 기준: 같은 의미의 ‘현재 주가 변화’는 공통 출처를 사용한다. 별도 이력 비교를 유지할 경우 비교한 두 날짜와 기간을 값 가까이에 명시한다. 시총도 snapshot 변화와 이력 변화의 의미를 구분한다.

### R3 · P1 · PBR 상세 CSV에서 BPS 결측을 실제 0으로 내보냄

- 근거: `lib/pbr-utils.ts:98`의 `Number(item.bps || 0)`와 `app/security/[secCode]/pbr/page.tsx:191`의 `bps: item.bps || 0`. PBR이 있는 기록의 BPS가 `null`/누락이면 최종 CSV에 숫자 0이 된다.
- 계획 위반: 4단계의 실제 0·null 구분과 전체 이력 데이터 의미 보존. 합산 과정의 의도적인 0 정책과는 다른 보조 지표 결측 처리다.
- 영향: 내려받은 데이터를 분석할 때 ‘BPS 미수집’과 ‘BPS 0’을 구분할 수 없다.
- 귀속과 범위: helper의 치환은 Git HEAD에도 있었다. 조건부 소스 경로는 확인했으며, 실제 한국가스공사 데이터에 결측 BPS가 있다고 주장하거나 해당 결측 fixture CSV를 이번에 다운로드한 것은 아니다.
- 처리 기준: 상세 CSV용 원본 null은 빈 셀로 보존하고 유효한 0은 숫자 0으로 유지한다. 차트 계산의 기존 정책과 다운로드 원본을 분리한다.

### R4 · P2 · 지표 이력이 없는 상세에서 공유·복사가 사라짐

- 근거: `components/detail-metric-empty.tsx:23`은 sticky 헤더에 actions를 전달하지 않으며, 빈 화면 안에 다른 공유/복사 컨트롤도 없다.
- 계획 위반: 공유와 정상 빈 상태도 적용 범위에 포함한다는 조건. PER/PBR/EPS/BPS/DIV/DPS 빈 화면에서 제목·종목·지표 탭은 유지된다.
- 영향: 데이터가 없는 지표 링크를 공유하려는 사용자에게 정상 상세와 다른 조작 경험을 제공한다. 브라우저 주소 복사로 우회할 수 있어 P2로 기록한다.
- 처리 기준: 빈 상태에도 같은 단일 헤더 액션을 제공한다. 없는 데이터를 다운로드하는 버튼을 추가할 필요는 없다.

### R5 · P2 · 320px 기업 상세의 연간 차트가 가로로 넘침

- 실제 증거: 320×844px 라이트 화면의 document overflow는 **5px**. 연간 차트 부모는 270px인데 차트는 300px, x25–325px로 배치됐다. 원래 1338px에서는 overflow 0이었다.
- 근거: `components/chart-company-marketcap.tsx:522`의 `minWidth={300}`. 개별 종목 차트 `components/chart-marketcap.tsx:175`에도 같은 최소 폭이 있어 수정 시 함께 확인해야 한다. 후자는 이번 실제 화면 측정의 대상이 아니다.
- 계획 위반: 1·3단계 및 인수 기준의 320px, 가로 넘침 없는 상세/차트.
- 영향: 화면 전체에 불필요한 가로 이동이 생기고 연간 차트가 본문 폭을 벗어난다.
- 증거 해석: 의도된 지표 탭 가로 스크롤을 문제로 세지 않았다. resize 직후 SVG path의 큰 임시 bounding box도 별도 결함으로 세지 않았다. 확정한 값은 responsive container의 최소 폭과 문서 overflow다.
- 처리 기준: 모바일 본문 안에 차트가 줄어들도록 최소 폭·카드 패딩을 조정하고, 축과 툴팁 가독성을 유지한다.

## 검증이 남은 항목

다음은 확인된 UI 결함과 구분한다. 아직 실행하지 않았거나 전체 성공 증거가 없어 완료 판정을 보류하는 항목이다.

- 최종 소스의 배포용 전체 28,020페이지 export. 직전 시도는 남은 디스크 여유 보호를 위해 완료 전 중단했다. 제한 export 240개 성공으로 대신할 수 없다.
- 전체 lint의 남은 73 errors/135 warnings. 이번에는 재실행하지 않았고 제품 소스도 바꾸지 않았다.
- 실제 OS 테마 변경, 200% 글자 확대, 브라우저 reduced-motion 환경. Provider 단위 테스트와 고정 슬롯 측정은 이 실제 환경의 대체 증거가 아니다.
- 모든 차트 렌더러의 실제 resize·기간 선택·empty/populated 전환과 native share 성공 흐름. 테스트/소스가 확인된 부분과 실제 기기 흐름의 범위를 구분해야 한다.

## 수정 순서와 인수 기준

1. R1 빈 시총 상세와 테스트 기대를 먼저 맞춘다. 알려진 종목의 이력 없음에서 탐색·공유가 유지되고, 없는 종목만 404여야 한다. R4도 같은 빈 상세 액션 계약으로 처리한다.
2. R2는 현재 주가/시총 변화와 이력 비교를 구분한다. 한국가스공사 같은 서로 다른 날짜의 데이터에서도 사용자가 각 변화율의 출처와 비교 기간을 읽을 수 있어야 한다.
3. R3은 결측 BPS와 실제 0이 담긴 상세 CSV로 확인한다. 전체 이력 행 수와 기존 계산을 유지한다.
4. R5는 기업·종목 차트를 320/390px에서 함께 확인한다. document overflow 0과 축/툴팁 접근을 기준으로 판단한다.
5. 위 기능 수정에 필요한 검증을 완료하고, 전체 export·lint·실제 환경의 남은 검사 결과를 인계 문서에 반영한다. 마무리는 새로운 시안 탐색보다 구현 계약을 맞추는 범위로 제한한다.

이번 점검에서 UI 수정과 새 design hook 억제는 **0건**이다. 앞선 비교 시안 전용 폰트 예외 4개는 기존 좁은 파일/값 범위에 그대로 두었다. 이번 다섯 미달은 모두 열린 상태이며 완료 또는 예외로 숨기지 않았다.
