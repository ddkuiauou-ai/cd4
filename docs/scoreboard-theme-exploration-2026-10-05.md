# 황금 전광판의 테마와 데스크톱 확장

2026-10-05 · 사용자가 나눔명조 ExtraBold와 A ‘황금 전광판’을 선호한다고 확인한 뒤 요청한 후속 시안이다. 제품 UI 구현 전 비교 단계다.

## 범위

같은 이름·가운데 별 SVG·실제 나눔명조 ExtraBold를 유지하며 다크/라이트 × 모바일/데스크톱 네 화면으로 비교한다. 다크 모바일은 기존 A v2를 사용한다. 라이트 모바일과 데스크톱 두 테마는 기존 A를 참조해 네이티브 imagegen으로 생성했다. 로고 영역은 비워 생성하고 브라우저에서 실제 텍스트와 원본 SVG로 표시한다.

새로운 메뉴·매매 기능·로그인·포트폴리오·대회 참가·광고 영역은 추가하지 않았다. 기존의 지표 선택·검색·기업 합산 범위·기준일·CSV 안내·전체 순위 연속 이동을 유지했다. 숫자와 추이는 이전 시안과 같은 예시이며 실제 시장 상태를 의미하지 않는다.

## 공통 규칙

- 브랜드: 나눔명조 ExtraBold 800, 붉은 ‘천하제일’, 기존 금색 원판과 붉은 별, 금색 ‘단타대회’, 얇은 검정 외곽선.
- 다크: 먹색 바탕, 밝은 수치, 금색 선택 밑줄과 다운로드 윤곽선, 가는 행 구분선.
- 라이트: 차가운 흰색 바탕, 먹색 수치, 금색 선택 밑줄과 금색 면의 다운로드 버튼. 크림 종이 질감이나 노란 상단 배너는 사용하지 않는다.
- 데스크톱: 헤더에서 로고·검색·최근 본을 가로 정렬하고, 기업명·추이·시가총액·등락을 분리한 하나의 연속 표를 사용한다.
- 모바일: 기존 A의 이름 → 검색 → 지표 → 제목·다운로드 → 순위 목록 읽기 순서를 유지한다.

- 단일 화면 뷰어: `.impeccable/logo-review/scoreboard-preview.html?device=desktop&theme=dark` (`device=mobile`, `theme=light` 지원)
- 로컬 서버: http://127.0.0.1:49673/scoreboard.html
- 생성 원본과 프롬프트: `.impeccable/mocks/scoreboard/`
- 실제 로고가 포함된 브라우저 캡처: `.impeccable/logo-review/review/scoreboard/`

최종 생성·편집 프롬프트: [다크 데스크톱](../.impeccable/mocks/scoreboard/desktop-dark.prompt.txt), [라이트 데스크톱](../.impeccable/mocks/scoreboard/desktop-light-v2.prompt.txt), [라이트 모바일](../.impeccable/mocks/scoreboard/mobile-light-v2.prompt.txt). 다크 모바일은 이전 A 이미지와 이번 실제 로고 배치를 재사용했다.

네이티브 imagegen 생성 결과는 인접 `.prompt.txt`, `.png.json`, PNG 내부 프롬프트에 출처를 보존했다. 시안 파일은 `approved:false`이며, 이번 테마·데스크톱 확장에 대한 사용자 선택 전이다. 실제 로고는 `.impeccable/logo-review/fonts/nanum.woff2`와 `assets/icon.svg`를 사용한다.

## 묶음 검토와 보정

첫 생성 결과를 함께 읽고 라이트 모바일의 금색 글자 대비, 라이트 데스크톱의 넓어진 표 폭을 보정 대상으로 정했다. 모바일의 선택 지표는 먹색, 다운로드는 금색 면 위 먹색, 1위는 진한 황토색으로 조정한다. 라이트 데스크톱은 다크 데스크톱을 두 번째 참조로 사용해 내용과 열·행 배치를 최대한 일치시킨다. 각각 한 번의 편집 생성으로 보정하며 최초 버전도 보존한다.

모바일 색 대비 보정은 반영되었다. 라이트 데스크톱의 폭·좌표를 맞추는 이미지 편집은 거의 반영되지 않아 다크보다 넓은 표와 다른 여백이 남아 있다. 이미지 모델로 정밀 좌표를 반복 보정하지 않고 두 시안을 그대로 비교한다. 선택 후 실제 구현에서 데스크톱의 공통 최대 폭과 열 위치를 동일한 CSS 규칙으로 확정해야 한다. 스파크라인 아래 일부 미세 음영도 이미지에 남아 있다.

브라우저 캡처는 데스크톱 1440×1000, 모바일 390×844의 네 화면을 저장했다. 실제 폰트 로딩, 이름 전체와 원본 별의 배치, 이미지 로딩, 가로 넘침을 확인한 값은 `review/scoreboard/render-validation.json`에 보존했다. 생성·편집 원본과 뷰어 복사본의 10개 PNG 출처 검사에서 누락은 없었다.

실제 폰트 합성 검토에서 라이트 데스크톱 헤더의 검색 중심선과 로고가 어긋난 것을 찾아 로고 위치만 해당 이미지의 시작선·검색 중심에 맞췄다. 생성된 본문 영역은 그대로 보존했다.

비교 페이지 바깥은 이전 검토에서 확정한 중립 회색을 유지한다. 본문은 이미지 시안이며 실제 UI의 반응형 재배치·키보드 조작·검색·다운로드 기능을 검증한 제품 구현이 아니다. 구현 시 정확한 폭과 행 높이, 차트의 수치 의미와 접근성은 별도로 확정한다.
