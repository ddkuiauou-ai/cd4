# Learnings

작업 키워드나 L번호로 찾는다. 각 항목의 **기준**은 지금 따를 문서, **근거**는 교정 당시의 사례·검증이다.

## 교훈을 정리할 때

- 사용자 교정이나 반복 가능한 실패는 수정하고 검증한 뒤 기록한다. 같은 원인은 기존 L번호에 합친다.
- 행동과 적용 범위가 확인되면 작업을 마치기 전에 담당 문서 한 곳에 반영한다. 개발·검증 절차는 분야별 Rules, 화면 결정은 DESIGN, 저장·조회·출력 계약은 해당 계약 문서가 기준이다. 이미 기준이 있으면 그 절을 연결한다.
- 색인에는 발생 조건·현재 행동·기준·근거를 짧게 남긴다. 적용 범위가 미확정이면 ‘검토 중’, 후속 결정이 바뀌면 ‘대체’와 새 기준을 적는다. 수치·시행착오·검증 한계는 당시 기록에 보존한다.

## L1 — 조회 오류·원천 최신일을 공개 결과로 오인

랭킹이 비거나 기준일이 오래됐을 때 공개 헤더와 결과 행을 함께 확인한다. 조회 실패·미공개·공개 0건을 구분한다. **기준** [공개 결과 조회](rules/data-temporal.md#보존할-저장조회-계약) · **근거** [랭킹 날짜와 오류 사례](ranking-fix-verification-2026-10-05.md)

## L2 — 결측·실제 0·종목 선택·값/날짜 쌍

여러 우선주나 희소 이력에서는 ID·선택 기간으로 대상을 정한다. 같은 관측의 값과 날짜를 쓰고 통계에서도 유효한 0을 보존한다. **기준** [저장·조회 계약](rules/data-temporal.md#보존할-저장조회-계약) · [상세의 대상 선택과 지표 제공 상태](../DESIGN.md#detail-navigation) · **근거** [0·결측과 상세 선택 반례](ui-plan-conformance-review-2026-10-05.md)

## L3 — 테스트·시안 승인과 UI 완료를 구분

UI 완료를 판단할 때 승인된 범위를 실제 화면·동작과 대조하고 테스트·사용자 수락·배포의 확인 범위를 밝힌다. **기준** [UI 구현과 확인](rules/ui.md#구현과-확인) · **근거** [승인 시안과 구현 대조](ui-plan-conformance-review-2026-10-05.md)

## L4 — 최근 본 종목의 로컬 중복·식별 기준

과거 SID나 시장이 다른 최근 기록이 남아 있으면 종목코드로 합친다. 가장 최근 방문 경로와 지표별 값을 보존하고 읽는 동안에는 저장하지 않는다. **기준** [최근 본 목록](../DESIGN.md#search-recent-and-theme) · **근거** [중복 회귀](../tests/recent-securities-deduplication.test.cjs) · [당시 브라우저 확인](archive/learning-evidence-2026-11-20.md#l4)

## L5 — 차트 방향 속성과 실제 CSS 색 연결

랭킹의 전일 주가 등락과 이전 순위 대비 이동은 각각 계산한다. 방향 속성이 실제 선 색에 반영되는지 두 테마에서 확인한다. **기준** [랭킹 색상](../DESIGN.md#colors) · **근거** [현재 차트](../components/ranking-quote.tsx) · [당시 색 검증](archive/learning-evidence-2026-11-20.md#l5)

## L6 — 깜박임의 대상·테두리·끝점 중심 확인

랭킹 끝점의 바깥 원 맥동은 **대체**됐다. 최종 표현은 중심이 투명한 금색 점선 원 하나이며, 마지막 관측이 유효할 때 실제 SVG 끝점과 중심을 맞춘다. **기준** [끝점 표시와 동작 예외](../DESIGN.md#colors) · **근거** [수정과 측정 이력](archive/learning-evidence-2026-11-20.md#l6)

## L7 — 모바일 지표 메뉴의 줄 수와 선택 항목 노출

좁은 랭킹의 두 줄 메뉴는 한 줄 가로 스크롤로 **대체**됐다. 가려진 선택 항목만 드러내고 페이지 세로 위치를 보존한다. 상세 지표 메뉴에는 별도 기준이 있다. **기준** [랭킹 지표 메뉴](../DESIGN.md#ranking-metric-first) · **근거** [폭별 메뉴 동작 확인](archive/learning-evidence-2026-11-20.md#l7)

## L8 — 반응형 시안은 중간 폭의 공간 배분부터 확인

랭킹 본문의 실제 폭을 기준으로 식별·지표 열의 읽기 폭을 확보하고 남는 공간을 차트에 준다. 중간 폭과 레일 전환도 확인한다. **기준** [랭킹 표 배치](../DESIGN.md#ranking-metric-first) · **근거** [시안 측정](archive/ranking-mock-review-2026-11-01.md) · [제품 적용](ranking-responsive-verification-2026-11-02.md)

## L9 — 넘침 검사와 실제 글자 정렬 검사를 구분

좁은 표에서 이름·코드·값을 쌓으면 실제 글자의 시작점과 읽기 순서를 비교한다. 부모 박스 안에 들어가도 텍스트는 어긋날 수 있다. **기준** [랭킹 표 정렬](../DESIGN.md#ranking-metric-first) · **근거** [320px 시안의 글자 좌표](archive/ranking-mock-review-2026-11-01.md)

## L10 — 작은 차트의 오버레이는 선분·끝점·최소 높이를 함께 확인

종가·등락률 글자가 연결선이나 끝점을 가리면 안전 배치로 전환한다. 글꼴 로딩·폭 변경 뒤에도 선의 가용 높이를 확인한다. **기준** [랭킹 차트 배치](../DESIGN.md#ranking-metric-first) · **근거** [시안 측정](archive/ranking-mock-review-2026-11-01.md) · [제품 브라우저 확인](ranking-responsive-verification-2026-11-02.md#실제-브라우저)

## L11 — 절대 배치한 숫자의 폭은 이전 위치에 의존하지 않게 한다

차트 안 숫자의 고유 폭을 위치와 독립적으로 측정한다. 화면을 줄였다 다시 넓힌 뒤에도 행 높이와 충돌을 확인한다. **기준** [숫자 오버레이](../DESIGN.md#ranking-metric-first) · **근거** [연속 폭 변경 재현](ranking-responsive-verification-2026-11-02.md#구현과-검토)

## L12 — 모바일 하단 메뉴와 데스크탑 푸터의 역할 중복

랭킹 모바일 하단은 자료 안내와 기존 메뉴로 마무리한다. 데스크탑 전용 목차는 공간과 포커스 대상에서 함께 빠져야 한다. **기준** [랭킹 하단](../DESIGN.md#ranking-footer-and-ending) · **근거** [푸터 적용과 검증 범위](ranking-footer-verification-2026-11-02.md)

## L13 — 외부 진입으로 열린 최근 패널의 클릭 순서와 포커스 소실

레일·푸터에서 연 패널이 같은 클릭으로 닫히지 않게 한다. 전체 삭제로 포커스가 본문으로 빠진 뒤에도 Escape로 닫고 호출 버튼으로 돌아갈 수 있어야 한다. **기준** [랭킹 최근 기록 진입](../DESIGN.md#ranking-footer-and-ending) · **근거** [패널 회귀](../tests/recent-panel.test.cjs) · [브라우저 확인](ranking-footer-verification-2026-11-02.md#실제-브라우저)

## L14 — 현행 설계 지침과 과거 작업 상태를 분리

설계가 바뀌면 현재 동작을 설명하는 문서와 구현 참조를 맞추고 대체된 시안·측정은 당시 기록에 연결한다. **기준** [현행 문서와 이력 관리](README.md#현재-지침과-기준) · **근거** [옛 렌더러 교체와 승인 자료 보존](ranking-cleanup-verification-2026-11-02.md#정리-범위)

## L15 — 프로덕션 빌드 전에 NODE_ENV 확인

개발 셸의 환경이 남은 채 프로덕션 빌드를 실행하면 사전 렌더링이 실패할 수 있다. 빌드할 때 적용되는 환경값을 확인한다. **기준** [빌드 실행 환경](rules/verification.md#실행-환경) · **근거** [실패 조건과 재검증](archive/learning-evidence-2026-11-20.md#l15)

## L16 — 기업 구성 종목과 상폐 이력의 조회 기준

기업 구성 카드·비교 표·시총 차트는 구성 기준일에 유효한 SID를 공유한다. 화면은 선정된 종목의 표시값만 보강하고 상장 중인 종목의 결측을 보존한다. **기준** [기업 구성과 기준일 대체 순서](security-lifecycle-contract-2026-10-13.md#웹-조회) · **근거** [상장 경계 회귀](../tests/security-lifecycle.test.cjs) · [서버·정적 표본 대조](archive/learning-evidence-2026-11-20.md#l16)

## L17 — 첫 검색 준비·목록 갱신과 최근 본 진입

첫 검색은 목록 준비 뒤 열고 갱신 중에는 직전 목록을 쓴다. 헤더의 최근 본은 전체 기록 레일이 실제로 보일 때만 숨긴다. **기준** [공통 헤더](../DESIGN.md#global-header) · [검색 진입](../DESIGN.md#search-recent-and-theme) · **근거** [헤더·검색 검증 범위](archive/learning-evidence-2026-11-20.md#l17)

공통 검색과 오타 추천에는 종목 공개 기준일의 상장 대상을 사용한다. 기존 상세 주소·별칭·사이트맵에는 상폐 종목도 남긴다. **기준** [검색 대상과 헤더 부재 시 기준](security-lifecycle-contract-2026-10-13.md#웹-조회) · [정적 출력](static-export.md#데이터와-화면) · **근거** [검색 회귀](../tests/search-listing-snapshot.test.cjs) · [코드 검색과 과거 CSV 대조](archive/learning-evidence-2026-11-20.md#l18)
