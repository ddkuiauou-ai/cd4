# Learnings

작업 키워드나 L번호로 찾는다. 각 항목의 **기준**은 지금 따를 문서, **근거**는 교정 당시의 사례·검증이다.

## 교훈을 정리할 때

- 사용자 교정이나 반복 가능한 실패는 수정하고 검증한 뒤 기록한다. 같은 원인은 기존 L번호에 합친다.
- 행동과 적용 범위가 확인되면 작업을 마치기 전에 담당 문서 한 곳에 반영한다. 개발·검증 절차는 분야별 Rules, 화면 결정은 DESIGN, 저장·조회·출력 계약은 해당 계약 문서가 기준이다. 이미 기준이 있으면 그 절을 연결한다.
- 색인에는 발생 조건·현재 행동·기준·근거를 짧게 남긴다. 적용 범위가 미확정이면 ‘검토 중’, 후속 결정이 바뀌면 ‘대체’와 새 기준을 적는다. 수치·시행착오·검증 한계는 당시 기록에 보존한다.

## L1 — 조회 오류·원천 최신일을 공개 결과로 오인

랭킹이 비거나 기준일이 오래됐을 때 공개 헤더와 결과 행을 함께 확인한다. 조회 실패·미공개·공개 0건을 구분한다. **기준** [공개 결과 조회](rules/data-temporal.md#보존할-저장조회-계약) · **근거** [랭킹 날짜와 오류 사례](ranking-fix-verification-2026-10-05.md)

## L2 — 결측·실제 0·종목 선택·값/날짜 쌍

여러 우선주나 희소 이력에서는 ID·선택 기간으로 대상을 정한다. 같은 관측의 값과 날짜를 쓰고 통계에서도 유효한 0을 보존한다. **기준** [저장·조회 계약](rules/data-temporal.md#보존할-저장조회-계약) · [상세의 대상 선택과 지표 제공 상태](../DESIGN.md#detail-navigation) · **근거** [0·결측과 상세 선택 반례](ui-plan-conformance-review-2026-10-05.md)

PER·PBR 분수와 EPS·BPS의 활용 예시는 종가·주당 지표·공개 배수의 날짜와 표시 정밀도를 확인한다. EPS와 BPS는 종가를 각각 PER과 PBR로 나눠 구하고, 반올림으로 금액이 달라지면 계산값과 공개값을 각각 표시한다. EPS·BPS의 1년 전 값은 비교 기준일 당일 또는 그 이전의 마지막 실제 관측을 고른다. 해당 날짜에 종가나 공개 배수가 없어도 주당 지표 자체는 표시한다. **기준** [재무·배당 지표 상세](../DESIGN.md#재무배당-지표-상세) · **근거** [분수의 날짜·반올림 회귀](../tests/detail-valuation-summary.test.cjs)

배당수익률은 주당배당금을 양수 종가로 나눈 비율이고 주당배당금은 종가에 배당수익률을 곱한 금액으로 설명한다. 두 상세의 현재와 1년 전 비교는 시점별 공개값과 입력값의 날짜를 맞추고 원값과 표시 숫자를 대조한다. 제공된 0%와 0원은 유효하다. **기준** [재무·배당 지표 상세](../DESIGN.md#재무배당-지표-상세) · **근거** [두 시점의 배당 계산 회귀](../tests/detail-valuation-summary.test.cjs)

배당 상세의 종목 간 비교는 선택 종목을 문장의 주어로 둔다. 종목 선택을 바꾸면 높고 낮음의 방향을 바꾼다. 두 시점의 격차 크기로 계산한 변화는 같은 종목 쌍에서 어느 쪽을 선택해도 같다. **기준** [재무·배당 지표 상세](../DESIGN.md#재무배당-지표-상세) · **근거** [종목 전환과 격차 변화 회귀](../tests/detail-context-navigation.test.cjs)

보통주·우선주를 전환하면 상세 지표 메뉴의 항목과 행 높이는 유지하고 제공 범위에 따라 링크 상태를 바꾼다. 비활성 항목은 화면에 남기고 클릭과 탭 이동 대상에서 제외한다. **기준** [상세 탐색](../DESIGN.md#detail-navigation) · **근거** [지표 순서와 비활성화 회귀](../tests/financial-metric-navigation.test.cjs)

기업 상세의 지표 메뉴에서 회사명과 같은 보통주의 반복 표기를 덜어낼 때는 지표 링크의 접근성 이름과 목적 종목을 확인한다. 같은 이름의 종목이 여럿이면 코드를 표시한다. **기준** [상세 탐색](../DESIGN.md#detail-navigation) · **근거** [기업 지표 메뉴 대상 표시 회귀](../tests/financial-metric-navigation.test.cjs)

모바일 지표 메뉴 여백의 탭은 브라우저가 가까운 링크로 전달할 수 있다. 안내가 열려 있으면 실제 터치 위치를 확인해 여백 탭으로 안내만 닫는다. **기준** [상세 탐색](../DESIGN.md#detail-navigation) · **근거** [미제공 안내 회귀](../tests/detail-record-info.test.cjs)

## L3 — 테스트·시안 승인과 UI 완료를 구분

UI 완료를 판단할 때 승인된 범위를 실제 화면·동작과 대조한다. 상세에서는 기록을 읽다가 우측에서 종목을 바꾼 뒤 뒤로 가서 스크롤 위치와 키보드 포커스를 확인한다. 각 목차 항목을 연 직후 현재 항목과 종목 전환의 목적 구간이 일치하는지 확인한다. 정적 화면은 차트와 이력이 로드된 뒤에도 같은 위치인지 확인한다. **기준** [UI 구현과 확인](rules/ui.md#구현과-확인) · **근거** [승인 시안과 구현 대조](ui-plan-conformance-review-2026-10-05.md) · [상세 목차와 종목 전환 회귀](../tests/detail-context-navigation.test.cjs)

BPS 상세의 분포와 히트맵은 스크롤해 두 차트가 실제로 그려지는지 확인한다. Turbopack 개발 모드에서 두 차트의 동적 모듈 활성화 오류를 재현해 `next/dynamic`으로 연결하고, 화면 근처에서 차트를 불러오는 동작을 유지했다. **기준** [UI 구현과 확인](rules/ui.md#구현과-확인) · **근거** [BPS 차트 연결](../components/restored-detail-charts.tsx) · [차트 회귀](../tests/chart-upgrade.test.cjs)

## L7 — 모바일 지표 메뉴의 줄 수와 선택 항목 노출

랭킹은 시총 두 보기를 각각 직접 열고, 다른 지표의 제목에는 종목별 순위임을 표시한다. 좁은 메뉴는 한 줄에서 가려진 선택 항목만 가로로 드러내고 페이지 세로 위치를 보존한다. **기준** [랭킹 지표 메뉴](../DESIGN.md#ranking-metric-first) · **근거** [순위 링크와 제목](../tests/ranking-view.test.cjs) · [선택 항목 노출](../tests/market-nav-scroll.test.cjs) · [기존 폭별 검증](archive/learning-evidence-2026-11-20.md#l7)

모바일 상세에서는 스크롤 중에도 지표를 바꿀 수 있도록 고정 제목의 현재 지표를 메뉴 버튼으로 쓴다. 좁은 폭과 긴 제목에서는 제목과 지표를 함께 두고 작업을 다음 줄로 보낸다. **기준** [상세 탐색](../DESIGN.md#detail-navigation) · **근거** [상세 탐색 회귀](../tests/detail-context-navigation.test.cjs)

모바일에서는 본문 목차가 고정 제목 뒤로 지나간 뒤 고정 제목의 ‘목차’를 사용한다. 전환 기준인 본문 목차의 공간을 유지해 경계에서 레이아웃이 움직이지 않도록 한다. 왼쪽 레일만 표시되는 폭에서는 지표 아래에 목차를 둔다. 창 높이가 충분하면 행과 그룹 사이를 넓히고, 낮은 창에서는 레일을 스크롤해 마지막 목차까지 접근할 수 있게 한다. **기준** [상세 탐색](../DESIGN.md#detail-navigation) · **근거** [상세 탐색 회귀](../tests/detail-context-navigation.test.cjs) · [레일 간격과 스크롤 높이](../components/detail-investor-navigation.module.css)

## L8 — 반응형 시안은 중간 폭의 공간 배분부터 확인

좌우 레일이 나타나는 중간 폭에서는 실제 본문 너비로 정렬을 확인한다. 랭킹은 식별·지표 열과 차트의 폭을, 상세는 긴 제목과 작업 버튼, 대표값과 순위의 기준선을 대조한다. [랭킹 표 배치](../DESIGN.md#ranking-metric-first) · [시안 측정](archive/ranking-mock-review-2026-11-01.md) · [상세 화면 검수](../.impeccable/surfaces/components-detail-surface-tsx.md#다운로드와-검수)

재무·배당 여섯 지표의 기록은 표 자체의 너비가 600px 이상일 때 관측일을 오른쪽 열로 전환한다. 삼성전자 상세의 808px 화면에서는 표가 약 595px여서 날짜가 연도 아래에 놓였고, 867px 화면에서는 표가 약 652px여서 오른쪽 열에 놓였다. 제공되는 우선주·보통주 차이가 있을 때도 날짜는 마지막 열에 둔다. **기준** [연도별 기록](../DESIGN.md#연도별-기록) · **근거** [연도별 기록 회귀](../tests/detail-restoration.test.cjs)

로딩 검수는 첫 HTML 응답과 이력 로딩을 각각 확인한다. 상위 경로의 공통 스켈레톤이 지표 전용 스켈레톤보다 먼저 보일 수 있다. [상세 로딩 경계 회귀](../tests/detail-metric-loading.test.cjs)

스크롤하면 줄어드는 상세 헤더는 고정 경계 앞뒤에서 한 번씩만 전환되는지 확인한다. PER 상세에서는 본문 스크롤 앵커 보정으로 고정 상태가 반복 전환되지 않게 하고, 좁은 폭의 작업 줄바꿈과 44px 조작 영역을 확인한다. CSV는 고정이 풀리는 프레임에도 금색 바탕이 바로 표시되는지 확인한다. **기준** [재무·배당 지표 상세](../DESIGN.md#재무배당-지표-상세) · **근거** [PER 고정 헤더 스타일](../components/detail-investor-summary.module.css)

시가총액 대상은 고정 제목 옆에서 합산과 종목코드·종류를 구분한다. 넓은 화면에서는 우측 핵심 지표 아래에 같은 너비의 전환 링크를 펼치고, 선택을 바꿔도 글자 위치를 유지한다. 좁은 화면에서는 고정 제목 옆에서 전환한다. 읽던 구간과 차트 기간을 복원하고, 선택 표시가 차트 강조색과 일치하는지 확인한다. **기준** [시가총액 상세](../DESIGN.md#시가총액-상세) · **근거** [시가총액 대상 전환 회귀](../tests/detail-context-navigation.test.cjs)

## L9 — 넘침 검사와 실제 글자 정렬 검사를 구분

넓은 표에서는 개별 열 제목의 기준선과 각 제목·데이터의 정렬축을 비교한다. 좁은 표에서 이름·코드·값을 쌓으면 실제 글자의 시작점과 읽기 순서를 비교한다. 상세 대표값은 빌드된 화면에서 숫자의 자간과 단위의 시작점도 비교한다. **기준** [랭킹 표 정렬](../DESIGN.md#ranking-metric-first) · [상세 대표값과 단위](../DESIGN.md#상세-대표값과-단위) · **근거** [공통 순위표 스타일](../components/ranking-view.module.css) · [320px 시안의 글자 좌표](archive/ranking-mock-review-2026-11-01.md) · [PER 대표값의 자간과 단위](../components/detail-investor-summary.module.css)

공통 헤더는 아이콘의 세로 중심과 함께 로고·주 메뉴 사이의 가로 간격, 헤더와 본문의 좌우 기준선을 확인한다. 화면 폭에 따라 검색 라벨과 주 메뉴가 바뀌는 경계 양쪽에서 전체 로고와 조작 영역을 확인한다. **기준** [공통 헤더](../DESIGN.md#global-header) · **근거** [헤더 배치와 폭별 여백](../app/globals.css)

## L17 — 첫 검색 준비·목록 갱신과 최근 본 진입

첫 검색은 목록 준비 뒤 열고 갱신 중에는 직전 목록을 쓴다. 최근 본은 모든 폭의 헤더에서 전체 기록을 연다. 우측 레일은 최신 3개로 시작해 마우스나 키보드로 최대 5개까지 펼친다. 미리보기와 목차 사이의 간격은 꺾쇠의 44px 조작 영역을 포함해 대조한다. 펼친 뒤 ‘전체 기록 보기’를 누르면 헤더 패널을 열고 첫 기록에 초점을 둔다. Escape는 원래 버튼으로 초점을 돌려준다. 각 행에는 실제 지표값과 짧은 지표명을 표시하고 값이 없으면 화면 이름을 쓴다. 한 줄이 좁은 행은 필요한 폭만 X 열에서 빌리고, 포인터나 키보드 초점에 맞춰 X를 겹친다. 터치에서는 X를 계속 표시한다. 개별 삭제를 헤더 기록과 공유한다. 50개가 들어 있어도 헤더의 기존 위치에서 열고, 레일 버튼과 겹칠 때는 스크롤 높이를 조정한다. **기준** [공통 헤더](../DESIGN.md#global-header) · [상세 탐색](../DESIGN.md#detail-navigation) · [검색과 최근 본](../DESIGN.md#search-recent-and-theme) · **근거** [방문 화면별 값 회귀](../tests/recent-securities-context.test.cjs) · [미리보기와 개별 삭제 회귀](../tests/ranking-bottom.test.cjs) · [패널 열기·닫기와 초점 회귀](../tests/recent-panel.test.cjs) · [헤더·검색 검증 범위](archive/learning-evidence-2026-11-20.md#l17)
