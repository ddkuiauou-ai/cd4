# 순위 변화 표현 비교

2026-10-05. 사용자는 기존 시안에서 빠진 순위 변화 정보를 포함하라고 요청했다. 이어 ‘복원’은 기능에 대한 의미이며 기존 UI 표현을 재현할 필요는 없다고 정정했다. 기존 시안의 로고, 테마, 메뉴, 우측 패널을 이어가면서 순위 정보의 표현을 다시 판단한다. 제품 구현 전 검토다.

## 정보의 의미

`components/rank-change.tsx`의 변화량은 `priorRank - currentRank`다. 이전4위에서 현재2위이면 두 계단 상승이고, 이전2위에서 현재3위이면 한 계단 하락이다. 지표 값이나 주가의 증감률이 아니다. 현재 구현은 변동0과 이전값 없음 모두 표시를 생략한다. 데스크톱 표는 순위 바로 옆, 모바일 목록은 순위 아래에 표시한다.

`docs/dag-integration.md:170`에 따르면 기업의 `marketcap_prior_rank`는 직전 거래일이 아니라 마지막 순위 변경 이전 값일 수 있다. 종목의 `prior_rank`는 해당 종목·지표의 더 이른 날짜 중 최신 기록이다. 따라서 새 표현은 ‘이전 순위 대비’로 안내한다. ‘전일 대비’, 새 진입, 실시간 순위라는 의미를 발명하지 않는다.

## 비교와 추천

| 형태 | 장점 | 비용 | 판단 |
|---|---|---|---|
| 큰 현재 순위 + 작은 수직 화살표·이동량 | 현재 위치와 움직임을 한 그룹에서 스캔 | 비교 기준의 짧은 설명 필요 | 기본 목록에 추천 |
| 작은 이전 순위 → 큰 현재 순위 | 출발점을 직접 확인 | 이동량을 계산해야 하며 목록마다 정보 반복 | 보조 설명에 채택 |
| 현재 순위와 순위 변화 열 분리 | 변화량끼리 비교하기 편리 | 연관 정보가 떨어지고 모바일 가로 공간 사용 | 변화량 비교가 별도 핵심인 화면에서 검토 |

추천안은 변화량에 중립색을 사용한다. 주가 등락은 기존 빨강·파랑과 %를 유지한다. 주가·차트에 쓰이는 꺾인 Trending 아이콘 대신 수직 방향의 일관된 SVG 화살표를 사용한다. 화살표와 절댓값만 표시하며 플러스·마이너스 부호를 중복하지 않는다. PER·PBR에서도 순위 이동은 투자 매력이나 수익의 개선으로 해석시키지 않는다. 금색 강조는 브랜드와 현재1위에 남긴다.

데스크톱은 큰 순위 옆, 모바일은 순위 아래에 작은 이동량을 둔다. 기업명과 기존 지표 열의 위치를 유지한다. hover·focus·탭으로 ‘이전4위 → 현재2위 · 두 계단 상승’을 확인하고 Escape로 닫을 수 있다. 기본 방향과 이동량은 보조 설명을 열지 않아도 보인다.

현재·이전이 동일하면 작고 중립적인 ‘유지’를 표시한다. 비교할 이전 순위가 없으면 변화량을 생략한다. 둘을 같은 상태로 표시하지 않는 새 제안이다. 시안에는 예시 이전 순위 `[1,4,2,5,3,6]`, 현재 순위 `[1,2,3,4,5,6]`을 사용한다. 삼성바이오로직스의 순위는 한 계단 상승하지만 주가는-4.51%인 예시로 두 값의 독립성을 보여준다.

## 결과물

- 비교: `http://127.0.0.1:49673/rank-movement.html?theme=light` — 세 가지 형태의 실제 텍스트·SVG 비교와 추천안의 데스크톱·모바일.
- 개별 화면: `rank-movement-preview.html?device=desktop|mobile&theme=light|dark`.
- 추천안은 기존 승인 방향의 이미지 위에 정밀한 HTML·SVG 순위 표시를 합성한다. 배경 PNG를 편집하지 않았고 제품 앱·컴포넌트를 변경하지 않았다. 실제 폰트와 원본 별 SVG도 이어간다. 이미지 안의 종목 이동·다운로드는 아직 구현 전이다.
- 데스크톱 배경: `.impeccable/logo-review/assets/navigation/ranking-light.png`, `ranking-dark.png`.
- 모바일 배경: `.impeccable/logo-review/assets/scoreboard/mobile-light-v2.png`, `assets/a-base.png`.

사용자 정정 전에 완료된 native imagegen 두 후보는 `.impeccable/mocks/rank-movement/desktop-light.png`, `desktop-dark.png`에 보관한다. 빨강·파랑과 Trending 방향을 사용해 주가 등락과 의미가 겹치는 문제가 있어 최종 추천 뷰어에는 사용하지 않는다. 정확한 프롬프트, PNG 내 출처, `approved:false` 메타데이터와 방향 변경 이유를 보존했다. 모바일 native 생성은 호출 전에 취소했고 추가 생성하지 않았다.

검토용 중립 회색 배경은 비교 자료의 바탕이다. 기존 황금 전광판의 라이트·다크 팔레트와 제품 콘텐츠를 그대로 이어간다. 추천안을 사용자 승인으로 간주하지 않는다.

## 확인

추천 시안 데스크톱1440×1080, 모바일390×844에서 두 테마를 함께 검토했다. 실제 나눔명조800·원본 SVG·PNG 로딩, 순위·회사명 간격, 여섯 행의 방향·변화량, 가로 넘침 없음을 확인했다. 중립색 대비는 라이트 변화량5.92:1·유지5.18:1, 다크 변화량11.33:1·유지8.66:1이다.

데스크톱·모바일 비교 뷰어의 세 형태, 한 열 재배치, 테마 전환과 링크의 테마 전달을 확인했다. 모바일 보조 설명의 탭·Escape 동작과 viewport 안에 머무는 위치를 확인했다. 최초 일괄 검토 뒤 모바일 변화량 글자를390px에서11.31px에서12.48px로 키우고 한 번 더 확인했다. JavaScript 구문 검사를 통과했다. 검증 캡처는 `.impeccable/logo-review/review/rank-movement/`에 저장했다.
