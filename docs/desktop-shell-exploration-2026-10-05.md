# 데스크톱 순위와 상세의 공통 구조

2026-10-05. 사용자는 모바일 라이트 테마를 좋아한다고 확인했으나 이전 데스크톱 시안은 모바일을 늘린 구성이라고 지적했다. 기존 삼성전자 상세의 우측 패널을 함께 검토한 뒤 순위·상세의 새 시안을 요청했다. 나눔명조 ExtraBold, 이름 가운데 기존 별 SVG, 황금 전광판의 색감은 유지한다. 제품 UI 구현 전 비교 단계다.

## 현재 화면에서 확인한 기능

실제 개발 서버의 `/company/KOSPI.005930/marketcap/`를 1440px에서 열어 상단과 차트 구간을 확인했다. 캡처는 `.impeccable/logo-review/review/desktop-shell/incumbent-detail-top.jpg`, `incumbent-detail-charts.jpg`다.

- 상세는 본문과 300px 우측 패널을 사용한다. 패널은 페이지 내비게이션, 지표 요약, 최근 본 종목, 같은 기업의 보통주·우선주 비교로 구성된다.
- 최근 본에는 종목 코드·시장과 방문한 지표 값이 함께 표시되며, 정렬·개별 삭제·전체 삭제가 있다.
- 기업 시가총액은 보통주와 우선주를 합산한다. 종목 상세의 값과 구분해야 한다.
- 회사 시가총액 상세에는 추이와 구성, 가격·거래량 차트, 종목 비교, 핵심 지표, 연도별 데이터·CSV가 있다. 현재 차트에 없는 기간 선택 버튼은 추가하지 않는다.
- 기본 `/security/[secCode]` 화면에는 이 우측 패널이 없다. 이번 검토 기준은 회사·종목의 지표 상세다.

근거: `app/company/[secCode]/marketcap/page.tsx`, `components/sidebar-manager.tsx`와 관련 패널 컴포넌트. 실제 기능 확인과 생성 시안의 재현은 구분한다.

## 이번 구성

순위와 상세에서 헤더·지표 메뉴·본문 시작선·우측 패널 폭을 함께 설계한다. 헤더는 로고, 검색, 테마 선택에 집중한다. 최근 본 종목은 두 화면의 우측 패널 상단에서 동일한 위치를 사용한다.

순위의 중심은 전체 기업을 이어서 읽는 표다. CSV 다운로드는 표 위에 둔다. 우측은 최근 본과 조회 기준을 제공한다. 클릭 전 선택한 기업의 요약은 현재 없는 기능이므로 만들지 않는다.

상세는 회사 이름과 합산 범위를 짧게 표시하고 넓은 시가총액 차트를 첫 화면에 배치한다. 가격·거래량과 보통주·우선주 구성은 다음 본문 영역에서 함께 읽는다. 우측에는 공통 최근 본과 상세에 맞는 핵심 지표·페이지 내비게이션·종목 비교를 둔다.

목표 좌표는 1440px 화면에서 좌우40px, 본문1028px, 간격32px, 우측300px다. 이미지 모델의 결과 좌표는 검토 후 아래에 별도로 기록한다. 실제 구현 시 하나의 CSS 그리드로 공통 폭을 고정해야 한다.

## 시안과 출처

생성 원본과 정확한 프롬프트는 `.impeccable/mocks/desktop-shell/`에 보존한다. 참고 이미지는 승인된 모바일 라이트를 색·룩앤필에, 실제 상세 캡처를 정보 구조와 기능에 사용한다. 로고는 생성 이미지에 맡기지 않고 브라우저에서 실제 나눔명조800과 원본 SVG를 합성한다.

표의 숫자와 차트는 2025.09.22 기준의 예시다. 회사 합산549조와 보통주494.3조·우선주54.3조를 구분한다. 실제 화면에서 서로 다른 날짜의 값이 섞여 보이는 현상을 발견했으며, 이 시안에서는 동일한 예시 기준으로 맞춘다. 데이터 수정은 이번 디자인 비교 범위에 포함하지 않았다.

생성 시안은 아직 `approved:false`다. 모바일 라이트의 기존 시안은 유지하며 생산 앱 소스는 변경하지 않는다.

최종 비교 페이지: `http://127.0.0.1:49673/desktop-shell.html?theme=light`. 라이트·다크 전환과 두 화면의 원래 크기 링크를 제공한다. 기존 모바일 라이트 뷰어도 연결했다.

## 묶음 검토와 남은 차이

두 라이트 초안을 함께 검토하고 패널 폭, 행 간격, 로고 빈 영역, 두꺼운 선택 표시를 한 번의 편집 생성으로 보정했다. 순위의 로고 placeholder와 상세의 두꺼운 금색 왼쪽 표시가 제거됐고 최근 본 항목은 간결해졌다. 다크는 각 라이트 최종본을 참조해 색만 바꾸는 편집으로 생성했다.

정밀 좌표 지시는 완전히 반영되지 않았다. 순위 원본1491×1055에서는 메인 약962px, 우측452px, 헤더92px, 행95px다. 상세 원본1448×1086에서는 메인 약996px, 우측384px, 헤더70px다. 두 화면의 헤더 높이·본문 밀도·우측 폭은 아직 통일되지 않았다. 정확한 좌표를 맞추려고 이미지 생성을 반복하지 않았다. 이 시안은 정보 구조와 색을 평가하는 자료이며, 구현 규칙은 헤더80px·지표56px·우측300px·순위 행64–72px의 공통 CSS로 고정한다.

최근 본을 같은 우측 상단 모듈로 이어가고 상세 차트를 본문 첫 화면에 배치한 것이 이번 변경의 핵심이다. 기업 합산549조와 보통주494.3조·우선주54.3조는 구분했다. 최근 본의 삼성전자494.3조는 종목 값이다. 순위 시안에는6개의 예시 행만 그렸으며 실제 서비스의 전체 기업 순위·페이지 이동 범위를 축소하는 결정은 아니다.

네이티브 생성 이미지와 뷰어 복사본 총10개 PNG의 embedded prompt 검사에서 누락은 없었다. 원본 별 SVG767B와 실제 글자만 포함한 나눔명조800 WOFF2 18040B를 사용한다. CSS에서 로고를 합성해 이미지 생성 글자에 의존하지 않는다.

## 렌더 확인

브라우저의1440×1080에서 순위·상세 두 테마를 저장했다. 실제 폰트 로딩, 모든 이미지 로딩, 이름 전체, 가로 넘침 없음, 테마 전환에 따른 이미지와 큰 화면 링크 변경을 확인했다. 비교 페이지는390×844에서 한 열로 표시되고 가로 넘침이 없다. 이 모바일 검사는 비교용 뷰어를 대상으로 하며 승인된 모바일 제품 시안을 변경한 것은 아니다.

- 실제 로고가 포함된 캡처: `.impeccable/logo-review/review/desktop-shell/{ranking,detail}-{light,dark}.jpg`
- 비교 캡처: `.impeccable/logo-review/review/desktop-shell/comparison.jpg`, `comparison-dark.jpg`
- 확인 값: `.impeccable/logo-review/review/desktop-shell/render-validation.json`
- 뷰어: `.impeccable/logo-review/desktop-shell.html`, `desktop-shell-preview.html`, `desktop-shell.css`, `desktop-shell.js`

뷰어 JavaScript 구문 검사를 통과했다. 검색·차트·CSV 등 제품 기능은 이미지이므로 기능 검증이나 생산 앱 구현을 완료했다고 주장하지 않는다. 기존 앱은 읽기와 화면 캡처에만 사용했으며 검토용 개발 서버는 종료했다. 정적 비교 서버49673은 계속 제공한다.

390px 비교 뷰어는 실제 viewport 관찰과 DOM에서 정상 배치를 확인했다. 전체 페이지 캡처 API가 이 배치와 다른 깨진 파일을 반환해 해당 모바일 캡처는 폐기했다. 데스크톱 보존 캡처는 각각 열어 화면 내용과 대조했다.
