# 사용자 지적 후 구현 계획 대조

2026-10-05. 사용자는 랭킹의 틀은 계획과 맞지만 메인이 임의로 바뀌었고 구현이 미완성으로 보인다고 지적했다. 이 문서는 소스 감사와 수정 사실을 기록한다. 테스트 성공만으로 디자인 완료를 선언하지 않는다.

## 확인한 미달과 수정

| 확인한 문제 | 수정 및 근거 |

상승·하락은 전체 시장 1위가 아니다. 기존 조회로 반환된 시총 상위 20개 기업의 대표 종목 내 비교라고 표시한다. 거래량 데이터는 해당 쿼리에 없으므로 기존 탭은 사실에 맞는 빈 상태를 유지한다. 데이터 수집·지표 계산·랭킹 URL·조회 캐시와 응답 캐시 헤더는 변경하지 않았다. 사이트맵 출력 설정과 내부 경로의 호환성 수정은 아래에 별도로 기록한다.

## 검증 상태

- 최종 전체 테스트: 155/155 통과. 상세 값·기준일, 같은 이름 우선주 선택, 희소 이력의 선택 없음·0값, 실제 공유 성공/실패 안내, mixed 날짜·후속 페이지 CSV 비교, 두 사이트맵 출력 모드와 native Next 라우팅 회귀 검증 포함.
- 실제 Section/Sidebar SSR에서 [0,100]은 평균 50·최저 0·최고 100, 전체 0은 통계 0으로 확인. 이력이 오래되면 오늘 기준 기간 평균은 결측이고 전체 평균은 유지. 이는 반례 fixture이며 실제 운영 데이터에 해당 오류가 발생했다고 주장하지 않는다.
- TypeScript: 통과.
- 최종 전체 ESLint: 73 errors / 135 warnings. 기준선의 기술 부채가 남아 있으며 통과로 표시하지 않는다. 무시 설정으로 숨기지 않았다.
- 실제 브라우저: 메인 1440/1024/390px 두 테마, 랭킹·기업/우선주 상세 1440/390px 두 테마, 모바일 공유 pin 확인. 해당 캡처 DOM에서 가로 넘침 0, 확인 시 콘솔 error/warn 없음.
- 모바일 pin 공유 그룹 y135–175, 하단 메뉴 y783–844. 공유 그룹은 sticky 헤더 내부의 정상 흐름이며 하단 fixed UI로 이동하지 않는다.
- 사용자 거부를 포함한 새 독립 전체 리뷰는 메인 구조가 계획과 의미상 부합함을 확인하고 상세 F1–F4 수정을 요구했다. 네 항목을 한 번에 수정한 뒤 같은 29개 화면을 다시 캡처했고, 후속 verdict에서 네 항목 모두 resolved 판정을 받았다. 이 판정은 네 수정 항목에 한정하며 사용자 수락이나 전체 인수 기준 통과를 의미하지 않는다.
- 최종 standalone 빌드: 통과, 334/334 정적 페이지 생성. `VERCEL=1`로 기존 4 workers 설정 사용.
- 최종 제한 정적 export 빌드: `--debug-build-paths`로 랭킹·메인·CSV·사이트맵을 선택해 240/240 생성 통과. 실제 CSV 8종의 BOM·18열·전체 행 수 및 sitemap index가 가리키는 8개 XML 파일의 존재·내용·사이트 origin을 확인. 상세 경로를 제외한 검증용 산출물이며 배포용 전체 export를 뜻하지 않는다.
- 전체 28,020페이지 export 시도는 디스크 여유를 보호하려고 완료 전에 중단했다. 최종 코드의 전체 export 완료는 미검증이다.
- 실제 `node .next/standalone/server.js`에서 메인·랭킹·기업/우선주 상세 4개 경로와 CSV 8종, 사이트맵 index와 8개 chunk 모두 HTTP 200 확인. 운영 사이트맵의 Next `Request.url` origin·포트와 기존 `Cache-Control: public, max-age=0, s-maxage=3600` 유지. Next는 loopback 요청의 `127.0.0.1`을 `localhost`로 정규화하므로 원시 Host 헤더를 그대로 전달한다는 주장과는 구분한다.

사이트맵 index는 정적 생성에 적합한 설정과 export 전용 사이트 origin을 사용한다. 분할 handler는 정적 export에서만 `generateStaticParams` 함수를 제공하고 운영에서는 제공하지 않아 요청별 응답을 유지한다. 내부 `[fileName]`은 `sitemap.xml`만 허용하며 잘못된 이름은 조회 전에 404로 처리한다. 조회 함수·XML 목록 생성·캐시 헤더는 유지했다. 운영/export가 기존 조회 모델에서 서로 다른 종목 범위를 선택하는 동작도 변경하지 않았다.

현재 증거는 `.impeccable/conformance-review/`의 캡처, `capture-context.json`, `review-packet.md`, `full-review.md`, `verdict.md`, `final-checks.json`, `export-artifacts.json`, `final-http.json`, `standalone-sitemap-http.json`에 있다. 수정 후 리뷰 캡처는 1440/1024/390px의 실제 너비·테마를 확인했고 가로 넘침 0, 해당 탭 콘솔 error/warn 없음이다. 별도의 `main-handoff-light.png`는 최종 운영 빌드를 사용자에게 보여주기 위한 1280px 결과 화면이며 추가 전체 리뷰가 아니다. 전체 정적 출력, 운영체제 실제 테마 변경·실제 200% 글자 확대·reduced-motion 환경은 검증하지 않았다. 후속 hook의 비교 시안 전용 폰트 경고는 네 alias 값·세 CSS 파일에 한정한 예외로 기록했다. 제품 파일이나 규칙 전체를 무시하지 않았으며 근거는 `prototype-font-hook-triage.md`에 있다.
