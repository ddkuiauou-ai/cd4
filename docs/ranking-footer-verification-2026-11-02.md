# 랭킹 하단·푸터 적용 검증 — 2026-11-02

## 적용 범위

사용자가 승인한 `ranking-directory-footer.html` 시안을 `/`와 기업 합산·모든 종목 지표 순위 및 후속 페이지에 적용했다. market layout만 AppShell의 새 footer 슬롯을 선택한다. 상세·대시보드는 기존 SiteFooter와 레일 구성을 유지한다. 기존 작업 트리의 변경을 보존했으며 배포·DB 쓰기는 수행하지 않았다.

## 구현과 검토

- 목록·페이지 이동과 최근 본 레일을 같은 그리드에 놓고 자료 안내는 그 다음 전체 폭으로 분리했다. 공개 기준일과 가격 관측 범위를 별도로 표시하며, 갱신 번호·공개 대상·단위·순위 이동 설명은 native details에 보존했다.
- 데스크탑 푸터는 실제 경로를 가진 서버 HTML 링크다. 768px 미만은 푸터 전체가 숨겨지고 기존 모바일 메뉴와 본문 안전 여백을 사용한다. 768–1099px는 브랜드 전체 폭과 세 탐색 그룹, 1100px 이상은 네 열이다.
- 랭킹 레일은 최대 네 기록, 높이 650px 미만에서는 세 기록을 표시한다. 폭 1280px 이상·높이 600px 이상에서만 sticky이고, 내부 스크롤을 제거했다. 전체 기록·삭제·지표 값은 기존 헤더 패널에 유지한다.
- `app:open-recent`로 레일·푸터의 버튼이 같은 패널을 연다. capture 단계의 바깥 클릭으로 같은 클릭에서 즉시 닫히는 일을 막았다. 브라우저에서 전체 삭제 후 focus가 BODY로 빠져 Escape가 동작하지 않는 문제를 재현한 뒤, 열린 패널에 한정한 document Escape 처리와 회귀로 수정했다.
- Impeccable의 실제 화면 검토와 별도 에이전트의 구조·React 검토를 수행했다. 추가 라이브러리·데이터 요청·스크롤 추적 JavaScript는 도입하지 않았다.

## 실제 브라우저

빌드된 standalone 앱을 임시 `127.0.0.1:3107`에서 실행해 확인했다. 기존 3001 개발 서버는 재시작하지 않았다.

- 라이트·다크 모두 **320/390/550/767/768/960/1099/1100/1279/1280/1440/1920px**에서 확인했다. 문서·하단 텍스트 가로 넘침, 모바일 메뉴 가림, 레일의 목록 경계 침범은 없었다. 모바일 푸터 높이는 0이며 목차 링크도 숨겨졌다.
- 최근 기록 10개에서 두 테마 모두 **1440×480/599/600/649/650px**를 확인했다. 600px 미만은 static, 600px 이상은 sticky였다. 650px 미만은 세 행, 650px 이상은 네 행이며 내부 overflow는 visible이었다.
- 실제 기업 방문과 삭제로 최근 기록 **0/1/4/10개**를 확인했다. 미리보기와 전체 패널의 삭제·전체 삭제가 동기화됐다. 레일·푸터 버튼에서 첫 기록으로 초점이 이동하고 Escape로 각 호출 버튼에 복귀했다. 빈 패널과 전체 삭제 후 Escape도 최종 실행본에서 통과했다. 긴 이름과 날짜·결측·미공개·0건·revision 변경은 추가 fixture 회귀로 확인했다.
- 푸터의 순위 링크 여덟 개가 쿼리 없이 각 첫 페이지 20행으로 이동했다. 주당배당금 다음 페이지는 `revision=43&scope=krx-all`을 유지하며 100행이었다. 기업/종목 전환, 상세 이동, 전체 2,665행 CSV 다운로드 시작 안내를 확인했다.
- ‘맨 위로’ 클릭 후 activeElement는 `ranking-title`, 제목 상단은 101px, 헤더 하단은 77px였다. 추가 scroll-margin 없이 기존 scroll-padding으로 가림을 피했다.
- 대시보드와 기업 상세에는 기존 푸터가 있고 새 목차 푸터는 없었다. 모바일 검색 dialog 열기·Escape, 테마 전환을 확인했다. 마지막 브라우저 콘솔의 error/warn은 없었다.

스크린샷과 측정 JSON은 기존 Git ignore 대상인 `.impeccable/review/2026-11-02-ranking-footer/`에 로컬 검토 자료로 보관한다. 검토용 서버는 종료하고 화면 크기·테마 설정을 복원한다.

전체 정적 export, 실기기·스크린리더 음성 검증, 운영 배포는 수행하지 않았다. 이 기록은 구현·검증 근거이며 사용자 최종 수락과 별개다.
