## 채택한 개선

### 조회·숫자·상태

- 화면용 조회 모델은 정확한 금액·정밀 숫자를 십진 문자열, 업무일을 `YYYY-MM-DD`로 전달한다. 회사 ID와 종목 ID를 분리한다.
- 상세 페이지의 공식 값·순위·연결 종목·이력·이웃 순위는 같은 읽기 전용 `REPEATABLE READ` 트랜잭션에서 읽는다. 랭킹은 해당 지표의 공개 헤더·행 수·revision과 맞춘다.
- 공식 포함 대상과 순위를 사용한다. 가격 부재·현재 상장 상태·음수 때문에 공식 순위 행을 제거하지 않는다.
- 정상 0건, 미공개, 값 결측, 갱신 충돌, 조회 오류를 구분한다. 마지막 제공값이나 오래된 정상값을 현재 값으로 올리지 않는다.
- 기준일을 값 가까이에 표시한다. 갱신번호는 접을 수 있는 자료 공개 설명으로 옮겼다. revision 충돌은 최신 자료 보기로 이어진다.
- 차트 좌표를 만들기 전에 큰 십진수의 상대 위치를 정확하게 계산한다. 툴팁·통계·CSV에는 원값을 유지한다. 실제 0·음수와 `null`을 구분한다.

### 랭킹·대시보드

- 첫 페이지 20개, 이후 100개 정책과 이전/다음 링크를 유지한다. 랭킹 가격 이력은 종목별 최근 30관측을 하나의 SQL 조회로 읽는다.
- 대표 보통주를 안정적으로 선택한다. 보통주·가격이 없는 회사도 공식 순위 행과 공식 총액을 유지한다.
- 대시보드 상승·하락·거래량은 시총 상위 20개 회사의 대표 보통주를 비교한다. 저장된 등락률과 실제 거래량을 사용하며 가격 기준일·날짜 범위를 표시한다.
- 최근 기록은 최신 방문순·기존 저장 키·최대 10개 정책을 유지한다. 기존 기록의 ID를 보완하고 지표 정보를 합치며, 모호한 코드는 임의 연결하지 않는다. 기본 상세·회사 상세를 방문한 경로도 보존한다. 여러 지표 순위의 평균 정렬은 복원하지 않았다.

### 종목 분석·가격 차트

- 전체 이력 조회의 100·180행 제한을 제거했다. 직접 지정 기간은 실제 분석 범위와 관측 시작일·종료일·개수에 반영된다. 각 기간 평균·최저·최고에도 실제 계산에 쓰인 관측 범위와 개수를 표시한다.
- DPS 기간 버튼을 실제 관측 범위에 연결했다. BPS 연도별 자료는 마지막 실제 12월 관측을 연말 값으로 사용한다. 그 외 지표의 연도별 마지막 관측은 연중 자료를 YTD로 구분한다.
- 전년 관측이 없는 경우 오래된 연도를 대신 사용하지 않는다. 증감률은 시작값이 양수일 때 계산한다. 실제 0%는 보존하고 시작값이 0·음수이면 정확한 차이값·이유를 표시한다. 현재값 비교·DPS 툴팁·연도별 표에 같은 정책을 적용한다. 비교 대상 자체가 없거나 회사 관측 구성이 바뀌면 비교 제외 사유를 표시한다.
- 각 필드의 부재는 독립적으로 처리한다. PBR이 제공되었는데 BPS가 없다는 이유로 PBR이나 CSV까지 지우지 않는다.
- 실제 OHLC가 있을 때 캔들을 표시하고 종가만 있으면 선·점으로 표시한다. 빠진 OHLC를 종가로 만들어 채우지 않는다.
- 5·10관측 이동평균은 필요한 선행 종가를 포함한 실제 관측으로 계산한다. OHLC가 없는 날의 제공 종가도 이동평균 원천으로 사용할 수 있으며 완전한 창부터 표시한다.
- 결측 구간은 끊고 단일 관측도 실제 점으로 표시한다. 월평균 차트는 원천 관측 개수와 표시 점 개수를 구분한다.

### 회사 구성·합산

- 공식 총액·순위·완전성·기준일을 그대로 사용한다. 등록 종목 이력 분석을 공식 총액 계산에 역으로 반영하지 않는다.
- 현재 회사에 연결된 분석 대상 종목의 실제 제공 이력을 연결했다. 신규 tem 런타임 의존성이 없다.
- 날짜별 정확한 부분 합계를 제공한다. 관측이 없으면 `null`, 실제 0은 0이다. 툴팁·단일 관측 설명·연도별 표·CSV에 관측 종목 수/분석 대상 종목 수를 포함한다.
- 합산 계열의 이름은 **등록 종목 합계**다. 두 비교 시점의 관측 종목 ID 집합이 다르면 합산 변화율을 표시하지 않는다.
- 구성비는 공식 기준일과 같은 날짜에 모든 분석 대상 값이 제공되고 정확한 합계가 공식 총액과 일치할 때 계산한다. 불완전하면 값과 결측 사유를 표시한다.
- 회사 요약 차트의 최근 3개월/전체 버튼은 실제 이력을 전환한다. 버튼은 차트 표시 범위이고 핵심 지표는 이름에 표시된 기간별 분석임을 설명한다. 직접 지정 기간에서는 두 영역에 지정 범위가 공통 적용된다. 회사 평균에는 관측 구성이 다른 날짜의 부분 합계도 포함될 수 있음을 명시한다.

### URL·검색·CSV

- 유일한 기존 `/security/KOSPI.005930/...`, `/company/KOSPI.005930/...` 경로를 유지한다. 재사용되어 모호한 코드는 안정 ID 경로를 사용한다.
- 검색·탭·공유·최근 기록·canonical·사이트맵이 공통 경로 생성 규칙을 사용한다. 회사 시총 탭과 선택 종목의 다른 지표 탭을 구분한다.
- 검색에서 이름·코드·거래소를 찾을 수 있고 같은 이름이나 재사용 코드를 가진 서로 다른 종목을 키보드로 구분하여 선택할 수 있다.
- 랭킹 CSV는 같은 지표·scope·revision으로 요청한다. 지표 이동에 이전 지표의 revision을 가져가지 않는다. 정상 0건의 헤더 전용 CSV를 성공 처리한다.
- CSV는 정확한 원값, 앞자리 0인 코드, 실제 0·음수, 빈 결측 셀을 유지한다. 갱신 충돌·미공개·장애를 구분한다.
- 상세 CSV는 차트와 같은 원천 이력의 **전체 제공 이력**을 다운로드한다. 기존 전체 이력 범위를 유지하기 위해 선택 기간과 별개임을 버튼 가까이에 표시했다.

### 검사 환경의 한계 및 기존 문제

- 기본 `pnpm build`의 Turbopack은 이 환경에서 CSS worker의 포트 생성이 `Operation not permitted`로 차단되어 완료되지 않았다. 설치된 CLI가 제공하는 `--webpack` 빌드로 검증했다. 기본 실행 명령·package 설정을 바꾸지 않았다.
- 전체 ESLint에는 **기존 파일의 오류 28개·경고 27개**가 남는다. 이번 변경 파일에는 오류·경고가 없다. 오류가 남는 파일은 `bps-chart-with-period-switcher.tsx`, `chart-EPS-enhanced.tsx`, `chart-a11y-description.tsx`, `marketcap-summary-expandable.tsx`, `spike-chart.tsx`, `lib/security-utils.ts`, `types/nav.ts`이며 주로 기존 `any`·빈 객체 타입이다. 전체 결과의 파일별 집계는 검증 JSON에 있다.
- 28개 경로는 HTTP와 페이지 테스트로 검사했고 모든 지표에서 모든 너비·테마 조합을 별도로 캡처한 것은 아니다. 반응형 전 조합은 대표 랭킹과 회사 상세에 적용했고 대시보드·종목 상세는 320px와 데스크톱을 확인했다.
