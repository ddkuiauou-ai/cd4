# 황금 전광판 구현 검증

2026-10-05 · 승인된 white-shell 시안과 구현 계획 기준. 배포와 커밋은 하지 않았다.

사용자 지적 후 [계획 대조 기록](./ui-plan-conformance-review-2026-10-05.md)에 메인 구조 누락과 실제 동작 미달을 기록하고 수정했다. 최종 코드의 테스트·타입·standalone 빌드와 수정 항목 재판정은 끝났다. 사이트맵 호환성도 두 실행 방식의 실제 파일·응답으로 확인했다. 전체 정적 출력과 아래의 실제 환경 검증은 남아 있어 전체 완료로 기록하지 않는다.

**최신 후속 구현:** [인수 기준 대조표](./ui-plan-acceptance-check-2026-10-05.md)의 R1–R5를 수정하고 최종 테스트 175/175·타입·standalone 334/334 및 수정 화면을 확인했다. [후속 구현 기록](./ui-plan-completion-2026-10-05.md)이 현재 판정이다. 아래 155개 테스트·제한 export 등의 기록은 당시 소스와 검증 범위이며 최종 소스의 전체 계획 완료를 뜻하지 않는다.

## 구현 범위

- 실제 나눔명조 ExtraBold 800과 원본 별 SVG, 전체 서비스 이름을 유지했다. 로고용 로컬 WOFF2는 18,040바이트이며 라이선스를 함께 저장했다.
- 공통 헤더·메인/랭킹·7개 지표·검색·최근 기록·모바일 탐색을 연결했다. 라이트 본문은 모바일·데스크톱 모두 흰색이며 데스크톱 보조 레일만 옅은 중립색이다.
- 17개 랭킹 경로와 기업·종목 상세, 7개 지표 차트·연도 표, 대시보드와 로딩·빈 결과·오류 화면에 같은 규칙을 적용했다.
- 첫 페이지 20행, 후속 페이지 100행과 기존 URL을 유지했다. 모바일에서 페이지의 모든 행을 볼 수 있고 가격이 없는 랭킹 행도 제외하지 않는다.
- 현재 순위와 중립색 이동량을 데스크톱에서는 나란히, 모바일에서는 같은 중심축에 묶었다. 상세 순위와 이전/다음 탐색은 같은 순위 기준일을 사용하고 결측 순위를 임의의 1위로 대체하지 않는다.
- 기업 합산/종목 범위와 지표의 전체 순위 CSV 8종을 제공한다. 지표 값·공식·데이터 수집을 변경하지 않았으며 상세 다운로드는 전체 이력을 유지한다.
- 차트 색상을 두 테마의 토큰에 연결했다. 캔버스 차트는 테마 전환 시 인스턴스·데이터·확대 범위를 유지한다. 차트 라이브러리의 로고를 직접 삭제하던 실행 오류도 수정했다.

실측은 `.impeccable/implementation-review/theme-geometry.json`에 저장했다. 실제 ThemeProvider 테스트는 시스템 기본값, 기기 설정 변경 이벤트, 수동 선택 저장과 재마운트, 다시 시스템 모드로 돌아가는 동작을 확인한다. 테스트 환경은 JSDOM이며 운영체제 설정을 직접 변경하거나 초기 HTML의 테마 스크립트를 실행한 검증은 아니다.

## 데이터·다운로드

실제 기업 합산 CSV를 내려받아 헤더를 제외한 2,601행, UTF-8 BOM, 숫자 값, 종목코드의 앞자리 0 보존, 기업별 지표 기준일을 확인했다. 빌드된 8종 CSV에서도 파일의 전체 행 수와 실제 행 수, 범위·지표·종목코드 처리를 확인했다. 기업 합산은 행별 기준일이 다를 수 있어 단일 순위 기준일을 만들어 넣지 않는다. 지표별 정렬은 화면과 같은 기존 공용 조회 규칙을 사용하며 저장된 순위를 다시 계산하지 않는다.

대시보드의 주가 흐름은 시가총액 상위 조회 기업 안에서 비교한다. 현재 이 조회 모델에 거래량이 없으므로 거래량 탭에 가격 순위를 대신 표시하지 않고 데이터 범위를 설명한다. 요약 스냅샷·가격·시총 이력의 날짜가 다르면 각각 표시한다. 이력이 한 날짜뿐이면 추이 선을 만들어내지 않고 해당 기록을 간결하게 보여준다.

초기 병렬 빌드는 디스크 공간 부족(ENOSPC)으로 산출물 복사/캐시 기록에서 실패했다. 개발 서버를 멈추고 이번 실행의 재생성 가능한 `.next` 산출물만 지운 뒤 기존 Vercel 설정의 4 workers로 빌드했을 때 통과했다. 사용자 파일이나 이전 작업의 임시 증거는 정리하지 않았다.

최종 검증 중 발견한 사이트맵 호환성은 공개 URL을 보존해 수정했다. 분할 handler의 내부 경로는 `[segment]/[fileName]`이며 `sitemap.xml`만 허용한다. export에서만 정적 params 함수를 등록하고 운영 서버에서는 동적 GET을 유지한다. index 및 분할 XML의 조회·내용 생성과 응답 캐시 헤더는 유지했다. 운영 origin은 Next가 전달한 `Request.url` 기준이며 loopback 정규화와 원시 Host 헤더 전달은 구분한다. 전체 export 중단은 디스크 부족 오류가 발생한 뒤의 실패가 아니라, 남은 여유를 보호하기 위한 중단이다.

## 화면 증거와 확인 한계

앞선 캡처와 수치는 `.impeccable/implementation-review/`, 사용자 지적 후 새 캡처는 `.impeccable/conformance-review/`에 있다. 저장된 시안과 실제 데이터의 날짜·값·행 수는 서로 다르며 시안의 예시 값을 제품에 넣지 않았다. 최종 디자인 규칙은 루트 `DESIGN.md`와 `.impeccable/design.json`을 따른다.

실제 200% 글자 확대와 reduced-motion 환경의 브라우저 에뮬레이션은 이번 도구에서 검증하지 않았다. 좁은 화면의 반응형, 포커스·키보드 가능한 제어와 reduced-motion CSS는 구현되어 있다. 전체 Lighthouse 측정, 실제 검색엔진 색인 결과, 모든 상장 종목의 시각 캡처를 수행했다는 의미는 아니다.
